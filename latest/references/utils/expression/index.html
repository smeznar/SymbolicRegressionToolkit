    Expression

    SRToolkit.utils.expression

    The Expression class: an expression with its free-constant specs.

    An Expression is the form that functions accept besides token lists. It holds the tokens, the symbol library they are written in and the specs of its labelled constants (see free_constants), and computes its tree and other facts once, so an expression used several times is parsed once.

    Expression 

    Expression(tokens: list[str] | tuple[str, ...], symbol_library: SymbolLibrary | None = None, free_constants: Sequence[Constant] | None = None)

    An immutable expression in a symbol library, with its free-constant specs, parsed on first use.

    An expression holds its infix tokens, the library they are written in, the specs of its labelled constants, and facts derived from them, each computed on first use and kept. Build one from tokens or with from_tree. Functions that take an expression accept a token list (an expression without specs) or an Expression, so an expression used several times is parsed once. Do not change the library after building an expression.

    The tokens are type-checked and the specs' labels checked when the expression is built, but the tokens are parsed only on first use, so a malformed expression can be built: parses is False and tree raises. parameter_labels, num_parameters and variables are read from the tokens without parsing, so they work on malformed expressions too.

    Parameters:

    Name Type Description Default
    tokens list[str] | tuple[str, ...]

    The expression as a list or tuple of infix token strings.

    		 required
    symbol_library SymbolLibrary | None

    The library the tokens are written in. None uses the active or default library, fixed when the expression is built.

    		 None
    free_constants Sequence[Constant] | None

    A sequence of Constant specs of labelled constants of the expression, in any order. None or empty: none; every parameter is fitted under the default spec.

    		 None

    Raises:

    Type Description
    TypeError

    If tokens is not a list or tuple of token strings, or free_constants is not a sequence of Constant (a single Constant is not a sequence; for a dict element the message points to Constant.from_dict).
    ValueError

    If a spec has no label, two specs share a label, or a spec's label is not a labelled constant of the expression.

    Examples:

    >>> sl = SymbolLibrary.default_symbols(2)
>>> g = Constant(label="C_0", value=9.81, fixed=True)
>>> expr = Expression(["C", "*", "X_1", "+", "C_0", "*", "X_0", "-", "C_0"], sl, [g])
>>> expr.num_parameters, expr.parameter_labels, expr.variables
(2, (None, 'C_0'), ('X_1', 'X_0'))
>>> expr.free_constants
(Constant(label='C_0', prior=None, bounds=None, value=9.81, fixed=True),)
>>> Expression(["X_0", "+"], sl).parses
False
    Notes

    Two expressions are equal, and hash equally, if their tokens are equal and their specs are equal in any order, whatever their libraries. Specs are compared by label, prior, bounds, value and fixed, with numbers compared as floats; an unset prior or bounds differs from an explicit one, even if they resolve the same. An expression never equals a token list.

    str joins the tokens with no separator (sin(X_0)). repr gives Expression([...]), with the specs if there are any and without the library. A pickled expression keeps only its tokens, library and specs.

    @classmethod
def from_tree(
    cls,
    tree: Node,
    symbol_library: SymbolLibrary | None = None,
    free_constants: Sequence[Constant] | None = None,
) -> "Expression":
    """Build an expression from a tree.

    The tokens are written out with [Node.to_list][SRToolkit.utils.expression_tree.Node.to_list];
    the tree is not kept, so the expression is the same as one built from these tokens. A
    malformed tree (e.g. an operator with one operand) gives tokens that do not parse.

    Args:
        tree: The expression tree.
        symbol_library: As for the constructor.
        free_constants: As for the constructor.

    Returns:
        The expression.

    Raises:
        TypeError: If ``tree`` is not a [Node][SRToolkit.utils.expression_tree.Node], or as for
            the constructor.
        ExpressionParseError: If a symbol of the tree is neither a number nor in the library.
        ValueError: As for the constructor.

    Examples:
        >>> tree = Node("+", Node("X_0"), Node("1"))
        >>> Expression.from_tree(tree, SymbolLibrary.default_symbols(1)).tokens
        ('1', '+', 'X_0')
    """
    if not isinstance(tree, Node):
        raise TypeError(f"tree must be a Node, got {type(tree).__name__}.")
    if symbol_library is None:
        symbol_library = SymbolLibrary.get_or_default()
    return cls(tree.to_list(symbol_library), symbol_library, free_constants)

    def resolve(self, default_constant: Constant) -> tuple[Constant, ...]:
    """Return one complete spec per parameter.

    As [resolve_constants][SRToolkit.utils.free_constants.resolve_constants] does for the
    expression's specs.

    Args:
        default_constant: The default spec, for parameters without a spec.

    Returns:
        One spec per parameter, in the order of
        [parameter_labels][SRToolkit.utils.expression.Expression.parameter_labels].

    Raises:
        ValueError: If ``default_constant`` is not a valid default spec, or a spec that is not
            fixed has a ``value`` outside the bounds it inherits from ``default_constant``.

    Examples:
        >>> from SRToolkit.utils.free_constants import uniform_default
        >>> spec = Constant(label="C_1", value=2.0, fixed=True)
        >>> expr = Expression(["C", "*", "X_0", "+", "C_1"], free_constants=[spec])
        >>> [(s.label, s.value, s.bounds) for s in expr.resolve(uniform_default((-5.0, 5.0)))]
        [(None, None, (-5.0, 5.0)), ('C_1', 2.0, (-5.0, 5.0))]
    """
    return resolve_constants(list(self._tokens), self._free_constants, default_constant, self._symbol_library)

    def to_latex(self) -> str:
    """Return the expression as a LaTeX string.

    Written by [Node.to_latex][SRToolkit.utils.expression_tree.Node.to_latex], which also numbers
    the constants.

    Returns:
        A LaTeX string of the form ``$...$``.

    Raises:
        ExpressionParseError: If the tokens are not a well-formed expression.
    """
    if self._latex is None:
        self._latex = self.tree.to_latex(self._symbol_library)
    return self._latex
