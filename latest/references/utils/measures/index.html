    Measures

    SRToolkit.utils.measures

    Measures that compare expressions with each other, and metrics that score predictions against data.

    Expression-to-expression measures take two expressions, each given as a list of token strings in infix notation (as parsed by tokens_to_tree) or as a Node tree:

    • edit_distance and tree_edit_distance are syntactic: they count token or node edits.
    • bed computes the Behavior-aware Expression Dissimilarity (BED), which compares what expressions compute rather than how they are written.

    An expression with free constants defines a family of functions, not a single one. BED evaluates each expression at points X for many constant vectors drawn by Latin Hypercube Sampling from the constants' priors, giving a behavior matrix of shape (n_points, n_constant_samples) (create_behavior_matrix). The priors come from the expression's specs (Constant); constants without a spec use the default spec (default_constant), by default a uniform prior on consts_bounds. A fixed constant keeps its value. The specs' fitting bounds play no role in BED. Row i is read as the distribution of the expression's output at X[i], and BED is the mean over points of the 1-D Wasserstein distance between corresponding rows. No constants are fitted, so BED can rank candidate structures during search; BEDRanking uses it as a ranking function. A behavior matrix can be computed once and passed to bed in place of an expression. See Mežnar et al., arXiv:2408.11515.

    Regression metrics (mse, rmse, mae, r2, nrmse) compare a model's predictions with targets. All share the signature metric(predict, X, y) -> float, where predict is a PredictFn with the model's fitted constants already bound in. Taking predict rather than precomputed predictions lets a metric also evaluate the model away from X, e.g. at perturbed or held-out points. Built-in metrics are listed by name in REGRESSION_METRICS, which SR_evaluator.get_metric uses; a user callable with the same signature can be used in place of a name.

    All metrics return a Python float and never emit NumPy warnings: an undefined or infinite result is returned as nan or inf (each metric lists when). predict(X) and y must both have shape (n_samples,); anything else raises ValueError.

    Functions that take symbol_library=None use SymbolLibrary.get_or_default: the library of the active context, else the one set with set_default, else default_symbols.

    Parameters are validated only when they are used. Invalid arguments raise TypeError or ValueError with a message that names the offending parameter.

    PredictFn module-attribute 

    PredictFn = Callable[[np.ndarray], np.ndarray]

    Type of a prediction function predict(X) -> y_pred, the first argument of every regression metric.

    It maps inputs of shape (n_samples, n_features) to predictions of shape (n_samples,), with the model's fitted constants already bound in.

    REGRESSION_METRICS module-attribute 

    REGRESSION_METRICS: Mapping[str, Callable[[PredictFn, ndarray, ndarray], float]] = MappingProxyType({'mse': mse, 'rmse': rmse, 'mae': mae, 'r2': r2, 'nrmse': nrmse})

    Read-only mapping from name to built-in regression metric.

    Keys are "mse", "rmse", "mae", "r2" and "nrmse"; every value has the signature metric(predict, X, y) -> float. SR_evaluator.get_metric uses it to resolve a metric given by name. The mapping cannot be modified; to use another metric, pass a callable with the same signature instead of a name.

    def edit_distance(
    expr1: list[str] | Node,
    expr2: list[str] | Node,
    notation: str = "postfix",
    symbol_library: SymbolLibrary | None = None,
) -> int:
    """Return the Levenshtein distance between the token sequences of two expressions.

    Both expressions are parsed and re-serialised in ``notation`` before comparison, so the result
    does not depend on whether a token list or a tree is passed, and redundant parentheses in a
    token list have no effect. Each token insertion, deletion or substitution costs 1, so the
    distance is symmetric.

    Args:
        expr1: First expression as an infix token list or a [Node][SRToolkit.utils.expression_tree.Node] tree.
        expr2: Second expression, in either form.
        notation: Notation in which the two expressions are compared: ``"infix"``, ``"prefix"`` or
            ``"postfix"``. It does not affect how token lists are read (always infix). In ``"infix"``,
            the parentheses needed to serialise an expression count as tokens; prefix and postfix
            contain none, hence the default ``"postfix"``.
        symbol_library: Symbol library used to parse and serialise the expressions. ``None`` uses
            the active or default library (see the module docstring).

    Returns:
        Number of token edits, ``>= 0``; ``0`` if and only if the serialised sequences are equal.

    Raises:
        TypeError: If an expression is neither a list of token strings nor a
            [Node][SRToolkit.utils.expression_tree.Node] (e.g. a string, a tuple, or a list with a
            non-string element).
        ValueError: If ``notation`` is not ``"infix"``, ``"prefix"`` or ``"postfix"``.
        ExpressionParseError: If a token list cannot be parsed: it is empty, malformed, or contains a
            symbol missing from ``symbol_library``.

    Examples:
        >>> edit_distance(["X_0", "+", "1"], ["X_0", "-", "1"])
        1
        >>> # The two parentheses count in infix notation
        >>> edit_distance(["(", "X_0", "+", "X_1", ")", "*", "X_0"], ["X_0", "+", "X_1", "*", "X_0"], notation="infix")
        2
    """
    if notation not in _NOTATIONS:
        raise ValueError(f"notation must be one of {_NOTATIONS}, got {notation!r}.")
    if symbol_library is None:
        symbol_library = SymbolLibrary.get_or_default()
    tokens1 = _as_tree(expr1, symbol_library, "expr1").to_list(symbol_library=symbol_library, notation=notation)
    tokens2 = _as_tree(expr2, symbol_library, "expr2").to_list(symbol_library=symbol_library, notation=notation)
    return _levenshtein(tokens1, tokens2)

    def tree_edit_distance(
    expr1: Node | list[str],
    expr2: Node | list[str],
    symbol_library: SymbolLibrary | None = None,
) -> int:
    """Return the Zhang-Shasha tree edit distance between two expressions.

    Unlike [edit_distance][SRToolkit.utils.measures.edit_distance], this compares expression trees,
    so notation and parentheses play no role. Each node insertion, deletion or relabelling costs 1;
    nodes match when their symbols are equal, and children are ordered (left, then right). The
    distance is symmetric.

    Args:
        expr1: First expression as an infix token list or a [Node][SRToolkit.utils.expression_tree.Node] tree.
        expr2: Second expression, in either form.
        symbol_library: Symbol library used to parse token lists. ``None`` uses the active or
            default library (see the module docstring).

    Returns:
        Minimum number of node edits, ``>= 0``; ``0`` if and only if the trees have the same symbols in
        the same ordered structure.

    Raises:
        TypeError: If an expression is neither a list of token strings nor a
            [Node][SRToolkit.utils.expression_tree.Node] (e.g. a string, a tuple, or a list with a
            non-string element).
        ExpressionParseError: If a token list cannot be parsed: it is empty, malformed, or contains a
            symbol missing from ``symbol_library``.

    Examples:
        >>> tree_edit_distance(["X_0", "+", "1"], ["X_0", "-", "1"])
        1
        >>> tree_edit_distance(["X_0", "+", "1"], ["X_0"])
        2
    """
    if symbol_library is None:
        symbol_library = SymbolLibrary.get_or_default()
    zss1 = _expr_to_zss(_as_tree(expr1, symbol_library, "expr1"))
    zss2 = _expr_to_zss(_as_tree(expr2, symbol_library, "expr2"))

    # Unit costs: zss otherwise uses the `editdistance` package (when installed) to price relabelling
    # by the character edit distance between symbols. zss is untyped; without return_operations=True
    # it returns just the cost.
    distance = cast(float, zss.simple_distance(zss1, zss2, label_dist=_unit_label_cost))
    return int(distance)

    create_behavior_matrix 

    create_behavior_matrix(expr: Node | list[str], X: ndarray, num_consts_sampled: int = 32, consts_bounds: tuple[float, float] = (-5, 5), symbol_library: SymbolLibrary | None = None, seed: int | None = None, backend: str = 'stack', free_constants: Sequence[Constant] | None = None, default_constant: Constant | None = None) -> np.ndarray

    • The n_free parameters that are not fixed share one Latin Hypercube sample of num_consts_sampled points in the unit cube [0, 1)^n_free, one dimension per parameter. If every free parameter uses the default spec built from consts_bounds, the constant vectors are a Latin Hypercube sample in [lower, upper)^n_free.

    Only priors and the values of fixed specs are used: bounds, and the value of a free spec, play no role, so samples follow the prior even outside bounds. Emits no NumPy floating-point warnings. Sampling is random unless seed is set.

    def create_behavior_matrix(
    expr: Node | list[str],
    X: np.ndarray,
    num_consts_sampled: int = 32,
    consts_bounds: tuple[float, float] = (-5, 5),
    symbol_library: SymbolLibrary | None = None,
    seed: int | None = None,
    backend: str = "stack",
    free_constants: Sequence[Constant] | None = None,
    default_constant: Constant | None = None,
) -> np.ndarray:
    """Evaluate an expression at the points ``X`` for many sampled constant vectors.

    Column ``j`` holds the expression's values at ``X`` with the ``j``-th constant vector. Each
    parameter's values come from its spec (a [Constant][SRToolkit.utils.free_constants.Constant]):

    - The ``n_free`` parameters that are not fixed share one Latin Hypercube sample of
      ``num_consts_sampled`` points in the unit cube ``[0, 1)^n_free``, one dimension per parameter.
      Each dimension is mapped through the parameter's prior's
      [ppf][SRToolkit.dataset.sampling.Sampler.ppf]; a prior without ``ppf`` is instead drawn from
      directly with a generator seeded by ``seed`` (independent draws, not stratified). If every free
      parameter uses the default spec built from ``consts_bounds``, the constant vectors are a Latin
      Hypercube sample in ``[lower, upper)^n_free``.
    - A fixed parameter has its ``value`` in every column.

    Only priors and the values of fixed specs are used: ``bounds``, and the ``value`` of a free spec,
    play no role, so samples follow the prior even outside ``bounds``. Emits no NumPy floating-point
    warnings. Sampling is random unless ``seed`` is set.

    Args:
        expr: Expression as an infix token list or a [Node][SRToolkit.utils.expression_tree.Node] tree.
        X: Evaluation points of shape ``(n_samples, n_features)``, with a column for every variable
            ``expr`` uses. ``n_samples`` may be 0, giving a result of shape ``(0, num_consts_sampled)``.
        num_consts_sampled: Number of constant vectors, i.e. output columns; at least 1.
        consts_bounds: ``(lower, upper)`` range of the default spec: shorthand for
            ``default_constant=uniform_default(consts_bounds)``, valid as for
            [uniform_default][SRToolkit.utils.free_constants.uniform_default]. Not used when
            ``default_constant`` is given.
        symbol_library: Symbol library used to compile ``expr``. ``None`` uses the active or default
            library (see the module docstring).
        seed: Seed for constant sampling. ``None`` gives a different sample on each call.
        backend: Backend used to compile expressions: ``"stack"`` (default), ``"stack_py"`` or
            ``"codegen"`` (see [compile_expr][SRToolkit.utils.expression_compiler.compile_expr]). All give
            the same values; ``"stack_py"`` can be faster for libraries with many custom symbols.
        free_constants: Specs for labelled constants of ``expr``, in any order; parameters without
            one use the default spec. ``None`` or empty: all use it.
        default_constant: The default spec: a template with ``prior`` and ``bounds`` set and no
            ``label``, ``value`` or ``fixed`` (``bounds`` are required although BED ignores them, as
            the same template serves fitting). ``None``: built from ``consts_bounds``.

    Returns:
        Behavior matrix of shape ``(n_samples, num_consts_sampled)``. Non-finite outputs (``nan``,
        ``±inf``) are kept. An expression without free parameters (no constants, or only fixed ones)
        gives ``num_consts_sampled`` identical columns.

    Raises:
        TypeError: If ``expr`` is neither a list of token strings nor a
            [Node][SRToolkit.utils.expression_tree.Node], or ``consts_bounds`` (when used) is not a
            pair of real numbers.
        ValueError: If ``X`` is not 2-D or has no column for a variable that ``expr`` uses, if
            ``num_consts_sampled < 1``, if ``consts_bounds`` (when used) is not finite with
            ``lower < upper``, if ``backend`` is not one of the backends above, if
            ``default_constant`` is not a valid template (see above), or if a spec in
            ``free_constants`` has no label, shares its label with another spec, names no labelled
            constant of ``expr``, or is free with a ``value`` outside the bounds it takes from
            ``default_constant``. The message names the offending argument.
        ExpressionParseError: If ``expr`` cannot be parsed or compiled with ``symbol_library``.

    Examples:
        >>> X = np.array([[0.0], [1.0], [2.0]])
        >>> create_behavior_matrix(["X_0", "+", "C"], X, num_consts_sampled=8, seed=0).shape
        (3, 8)
        >>> fixed = Constant(label="C_1", value=2.0, fixed=True)
        >>> create_behavior_matrix(["C_1", "*", "X_0"], X, num_consts_sampled=2, free_constants=[fixed])
        array([[0., 0.],
               [2., 2.],
               [4., 4.]])
    """
    if num_consts_sampled < 1:
        raise ValueError(f"num_consts_sampled must be at least 1, got {num_consts_sampled}.")
    default = default_constant
    if default is None:
        try:
            default = uniform_default(consts_bounds)
        except (TypeError, ValueError) as e:
            raise type(e)(f"consts_bounds: {e}") from None
    X = np.asarray(X, dtype=np.float64)
    if X.ndim != 2:
        raise ValueError(f"X must be 2-D with shape (n_samples, n_features), got shape {X.shape}.")
    if symbol_library is None:
        symbol_library = SymbolLibrary.get_or_default()

    tree = _as_tree(expr, symbol_library, "expr")
    specs = resolve_constants(tree, free_constants, default, symbol_library)
    callable_expr = compile_expr(tree, symbol_library, backend=backend)

    # One row per constant vector: fixed values in place, free columns sampled below.
    constants = np.tile([s.value if s.fixed else np.nan for s in specs], (num_consts_sampled, 1))
    free = [i for i, s in enumerate(specs) if not s.fixed]
    with np.errstate(all="ignore"):
        if not free:
            return np.repeat(callable_expr(X, constants[0] if specs else None)[:, None], num_consts_sampled, axis=1)
        # One generator: the Latin Hypercube sample first, then draws for priors without ppf.
        rng = np.random.default_rng(seed)
        unit = LatinHypercube(len(free), rng=rng).random(num_consts_sampled)
        for k, i in enumerate(free):
            prior = specs[i].prior
            assert prior is not None  # set by resolve_constants
            try:
                constants[:, i] = prior.ppf(unit[:, k])
            except NotImplementedError:
                constants[:, i] = prior(num_consts_sampled, rng=rng)
        columns = [callable_expr(X, c) for c in constants]
        return np.stack(columns, axis=1)

    bed 

    bed(expr1: Node | list[str] | ndarray, expr2: Node | list[str] | ndarray, X: ndarray | None = None, num_consts_sampled: int = 32, num_points_sampled: int = 64, domain_bounds: list[tuple[float, float]] | None = None, consts_bounds: tuple[float, float] = (-5, 5), symbol_library: SymbolLibrary | None = None, seed: int | None = None, backend: str = 'stack', free_constants1: Sequence[Constant] | None = None, free_constants2: Sequence[Constant] | None = None, default_constant: Constant | None = None) -> float

    def bed(
    expr1: Node | list[str] | np.ndarray,
    expr2: Node | list[str] | np.ndarray,
    X: np.ndarray | None = None,
    num_consts_sampled: int = 32,
    num_points_sampled: int = 64,
    domain_bounds: list[tuple[float, float]] | None = None,
    consts_bounds: tuple[float, float] = (-5, 5),
    symbol_library: SymbolLibrary | None = None,
    seed: int | None = None,
    backend: str = "stack",
    free_constants1: Sequence[Constant] | None = None,
    free_constants2: Sequence[Constant] | None = None,
    default_constant: Constant | None = None,
) -> float:
    """Return the Behavior-aware Expression Dissimilarity (BED) between two expressions.

    Each expression is turned into a behavior matrix over the same points (see
    [create_behavior_matrix][SRToolkit.utils.measures.create_behavior_matrix]), and BED is the mean
    over points of the 1-D Wasserstein distance between the two rows. A precomputed behavior matrix
    can be passed in place of an expression to avoid re-evaluating it. The points depend on the
    arguments:

    - **Two matrices** are compared directly, and must have been computed at the same points. If
      ``X`` is given, it is only used to check that each matrix has ``len(X)`` rows.
    - **At least one expression, with ``X``**: expressions are evaluated at ``X``, and a matrix
      argument must have been computed at ``X`` (``len(X)`` rows). ``domain_bounds`` is ignored.
    - **Two expressions, without ``X``**: ``num_points_sampled`` points are drawn from
      ``domain_bounds`` by Latin Hypercube Sampling.
    - **An expression and a matrix, without ``X``** is an error: the matrix's points are unknown.

    Args:
        expr1: First expression as an infix token list, a [Node][SRToolkit.utils.expression_tree.Node] tree,
            or a behavior matrix of shape ``(n_samples, k1)`` with ``k1 >= 1``.
        expr2: Second expression, in any of the same forms. A matrix may have a different number of
            columns than ``expr1``.
        X: Points of shape ``(n_samples, n_features)`` at which expression arguments are evaluated,
            with a column for every variable used. Required when exactly one argument is a matrix;
            with two matrices, only their row count is checked against it.
        num_consts_sampled: Constant vectors sampled per expression argument (its matrix columns);
            at least 1. Not used for matrix arguments.
        num_points_sampled: Number of points drawn from ``domain_bounds``; at least 1. Used only in
            that mode.
        domain_bounds: One ``(lower, upper)`` interval per variable, with ``lower < upper``, covering
            every variable used. Used only when ``X`` is ``None`` and neither argument is a matrix.
        consts_bounds: ``(lower, upper)`` range of the default spec, as in
            [create_behavior_matrix][SRToolkit.utils.measures.create_behavior_matrix]. Not used for
            matrix arguments or when ``default_constant`` is given; otherwise validated whenever an
            argument is an expression.
        symbol_library: Symbol library used to compile expressions. ``None`` uses the active or
            default library (see the module docstring).
        seed: Seed for all sampling: the points and the constants of both expressions. ``None``
            makes the result random whenever points are sampled or an expression has free (not fixed)
            parameters.
        backend: Backend used to compile expression arguments: ``"stack"`` (default), ``"stack_py"`` or
            ``"codegen"`` (see [compile_expr][SRToolkit.utils.expression_compiler.compile_expr]). All give
            the same values; ``"stack_py"`` can be faster for libraries with many custom symbols.
        free_constants1: Specs ([Constant][SRToolkit.utils.free_constants.Constant]) for labelled
            constants of ``expr1``, as in ``create_behavior_matrix``. Not used if ``expr1`` is a matrix.
        free_constants2: Specs for labelled constants of ``expr2``, likewise.
        default_constant: The default spec for both expressions, as in ``create_behavior_matrix``.

    Returns:
        BED as a float ``>= 0``; ``0.0`` for identical behavior at the points. Each point's (row's)
        distance is found by these steps, in order:

        1. ``nan`` entries are dropped from both rows.
        2. If both rows are now empty, the distance is 0; if only one is, it is ``inf``.
        3. If either row contains ``±inf``: 0 if both rows hold only the same infinity, else ``inf``.
        4. Otherwise, the distance is the Wasserstein distance between the remaining samples.

        If any point's distance is ``inf``, BED is ``inf``.

    Raises:
        TypeError: If an argument is neither a list of token strings, a
            [Node][SRToolkit.utils.expression_tree.Node] nor a ``numpy.ndarray``, or an argument is
            an expression and ``consts_bounds`` (when used) is not a pair of real numbers.
        ValueError: If any of the following holds (the message names the offending argument):

            - ``X`` is ``None`` and either exactly one argument is a matrix, or neither
              ``domain_bounds`` nor two matrices are given;
            - ``X`` is given and is not 2-D, or a matrix argument's row count differs from ``len(X)``;
            - a matrix argument is not 2-D or has no columns;
            - the two behaviors have different numbers of rows or none (including an ``X`` with 0
              rows at which an expression is evaluated);
            - points are sampled and ``num_points_sampled < 1`` or an interval in ``domain_bounds``
              has ``lower >= upper``;
            - ``X`` or ``domain_bounds`` lacks a column for a variable used;
            - an argument is an expression (even one without constants) and ``num_consts_sampled < 1``,
              ``consts_bounds`` (when used) is not finite with ``lower < upper``, ``backend`` is
              unknown, or ``default_constant`` or its specs are invalid (see
              ``create_behavior_matrix``).
        ExpressionParseError: If an expression cannot be parsed or compiled with ``symbol_library``.

    Examples:
        >>> X = np.linspace(-1, 1, 20).reshape(-1, 1)
        >>> bed(["X_0"], ["X_0", "+", "1"], X)
        1.0
        >>> bed(["C", "*", "X_0"], ["C", "+", "X_0"], domain_bounds=[(-1, 1)], seed=0) > 0
        True
        >>> # Reuse a precomputed behavior matrix, e.g. of a ground truth
        >>> gt = create_behavior_matrix(["X_0", "+", "C"], X, seed=0)
        >>> bed(["X_0", "+", "C"], gt, X, seed=0)
        0.0

    Notes:
        With rows ``u_i`` and ``v_i`` of the two behavior matrices read as empirical distributions,
        ``BED = (1 / n_samples) * sum_i d_i``, where ``d_i`` is the 1-D Wasserstein distance
        ``W1(u_i, v_i)`` after the non-finite steps in Returns. Every point counts in ``n_samples``,
        including those given distance 0 by those steps.

        As a consequence of seeding, with ``seed`` set ``bed`` is deterministic; it is symmetric
        when the specs are swapped with the expressions (``bed(e1, e2, free_constants1=s1,
        free_constants2=s2) == bed(e2, e1, free_constants1=s2, free_constants2=s1)``), and
        ``bed(e, e) == 0`` when both sides get the same specs. With ``seed=None``, ``bed(e, e)`` can
        be greater than 0 for an expression with free (not fixed) parameters.

    References:
        S. Mežnar, S. Džeroski, L. Todorovski. Quantifying Behavioral Dissimilarity Between
        Mathematical Expressions. [arXiv:2408.11515](https://arxiv.org/abs/2408.11515).
    """
    if symbol_library is None:
        symbol_library = SymbolLibrary.get_or_default()
    # Expressions become Node trees (parsed once); matrices are checked for shape.
    trees: dict[str, Node] = {}
    matrices: dict[str, np.ndarray] = {}
    for name, arg in (("expr1", expr1), ("expr2", expr2)):
        if isinstance(arg, np.ndarray):
            if arg.ndim != 2 or arg.shape[1] == 0:
                raise ValueError(
                    f"{name} must be a behavior matrix of shape (n_samples, k) with k >= 1, got {arg.shape}."
                )
            matrices[name] = arg
        elif isinstance(arg, (list, Node)):
            trees[name] = _as_tree(arg, symbol_library, name)
        else:
            raise TypeError(
                f"{name} must be a list of token strings, a Node or a numpy.ndarray, got {type(arg).__name__}."
            )

    if X is not None:
        X = np.asarray(X, dtype=np.float64)
        if X.ndim != 2:
            raise ValueError(f"X must be 2-D with shape (n_samples, n_features), got shape {X.shape}.")
        if X.shape[0] == 0:
            raise ValueError("X must contain at least one point (row).")
        for name, matrix in matrices.items():
            if matrix.shape[0] != X.shape[0]:
                raise ValueError(f"{name} has {matrix.shape[0]} rows, but X has {X.shape[0]} points.")
    elif len(matrices) == 1:
        raise ValueError("X must be given when exactly one of expr1 and expr2 is a behavior matrix.")
    elif not matrices:
        X = _sample_points(trees["expr1"], trees["expr2"], num_points_sampled, domain_bounds, symbol_library, seed)
    else:
        rows1, rows2 = matrices["expr1"].shape[0], matrices["expr2"].shape[0]
        if rows1 != rows2:
            raise ValueError(f"expr1 and expr2 must have the same number of rows, got {rows1} and {rows2}.")
        if rows1 == 0:
            raise ValueError("expr1 and expr2 must have at least one row.")

    def behavior(name: str) -> np.ndarray:
        if name in matrices:
            return matrices[name]
        # An expression argument always has points: X was given, or it was sampled above.
        assert X is not None
        specs = free_constants1 if name == "expr1" else free_constants2
        return create_behavior_matrix(
            trees[name], X, num_consts_sampled, consts_bounds, symbol_library, seed, backend, specs, default_constant
        )

    return _mean_row_distance(behavior("expr1"), behavior("expr2"))

    def r2(predict: PredictFn, X: np.ndarray, y: np.ndarray) -> float:
    """Return the coefficient of determination R² of a model's predictions.

    Args:
        predict: Callable mapping ``X`` to predictions of shape ``(n_samples,)``. Exceptions it
            raises propagate.
        X: Input data of shape ``(n_samples, n_features)``.
        y: Targets of shape ``(n_samples,)``, as any array-like (converted with ``np.asarray``).

    Returns:
        ``1 - SS_res / SS_tot``, with ``SS_res = sum((y - predict(X)) ** 2)`` and
        ``SS_tot = sum((y - mean(y)) ** 2)``; at most 1, higher is better. Special cases, checked
        in this order (a prediction is exact if it equals its target exactly):

        - ``nan`` if there are no samples, a target is ``nan`` or infinite, or a prediction is ``nan``;
        - if all targets are equal (also for one sample): ``1.0`` if all predictions are exact, else ``-inf``;
        - ``-inf`` if a prediction is infinite.

    Raises:
        ValueError: If ``predict(X)`` or ``y`` is not 1-D of length ``n_samples``.

    Examples:
        >>> r2(lambda X: X[:, 0], np.array([[1.0], [2.0], [3.0]]), np.array([1.0, 2.0, 4.0]))
        0.7857142857142857
    """
    y_pred, y = _predictions_and_targets(predict, X, y)
    special = _normalised_metric_special_value(y_pred, y, perfect=1.0, worst=-np.inf)
    if special is not None:
        return special
    with np.errstate(all="ignore"):
        return float(1 - np.sum((y - y_pred) ** 2) / np.sum((y - np.mean(y)) ** 2))

    def nrmse(predict: PredictFn, X: np.ndarray, y: np.ndarray) -> float:
    """Return the root-mean-square error of a model's predictions, normalised by the spread of the targets.

    Args:
        predict: Callable mapping ``X`` to predictions of shape ``(n_samples,)``. Exceptions it
            raises propagate.
        X: Input data of shape ``(n_samples, n_features)``.
        y: Targets of shape ``(n_samples,)``, as any array-like (converted with ``np.asarray``).

    Returns:
        ``rmse / std(y)``, with the population standard deviation (``ddof=0``); ``>= 0``, lower is
        better. Special cases, checked in this order (a prediction is exact if it equals its target
        exactly):

        - ``nan`` if there are no samples, a target is ``nan`` or infinite, or a prediction is ``nan``;
        - if all targets are equal (also for one sample): ``0.0`` if all predictions are exact, else ``inf``;
        - ``inf`` if a prediction is infinite.

    Raises:
        ValueError: If ``predict(X)`` or ``y`` is not 1-D of length ``n_samples``.

    Examples:
        >>> nrmse(lambda X: X[:, 0], np.array([[1.0], [2.0], [3.0]]), np.array([1.0, 2.0, 4.0]))
        0.46291004988627577
    """
    y_pred, y = _predictions_and_targets(predict, X, y)
    special = _normalised_metric_special_value(y_pred, y, perfect=0.0, worst=np.inf)
    if special is not None:
        return special
    with np.errstate(all="ignore"):
        return float(np.sqrt(np.mean((y - y_pred) ** 2)) / np.std(y))
