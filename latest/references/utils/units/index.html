    Units

    SRToolkit.utils.units

    Physical units of variables, constants and targets.

    A Unit is a product of base dimensions raised to rational exponents, e.g. metres per second is m s^-1. The predefined units are constants of this module, named by their SI symbols, and combine with *, / and **:

    from SRToolkit.utils import units as u

velocity = u.m / u.s
entropy = u.J / u.K
u.J == u.kg * u.m**2 / u.s**2  # True: derived units are products of base units

    A misspelled name (u.meter) is an AttributeError. The predefined units are the seven SI base units m, kg, s, A, K, mol, cd and the derived units N, J, W, Pa, Hz, C (coulomb), V, Ohm, F, T. A unit is a dimension, not a scale, so there are no prefixes: a kilometre has the unit m. State the scale of the data in the variable's VariableInfo description instead, e.g. VariableInfo("d", "distance in km", u.m). Checks such as ConsistentUnits treat km and m alike; a free constant absorbs the conversion factor.

    Custom units

    Unit builds a unit from a dict of exponents. Its names must be predefined units, so a typo such as "meter" is an error, unless they are confirmed as custom units, e.g. for information or money:

    from SRToolkit.utils.units import Unit

rate = Unit({"bit": 1, "s": -1}, custom_units=["bit"])
BIT = Unit({"bit": 1}, custom_units=["bit"])  # or name it once and combine
rate == BIT / u.s  # True

    custom_units declares new base dimensions. A unit made of existing ones is built with arithmetic instead, e.g. a litre is u.m**3: Unit({"L": 1}, custom_units=["L"]) would be a new dimension that does not match m^3.

    Saving and reading

    to_dict writes a unit as {dimension: exponent} over base dimensions, with the exponents as strings ({"m": "1", "s": "-1"}), and from_dict rebuilds it without confirmation: a saved unit was valid when it was made. str is for reading only: "kg m^2 s^-2", "m^(1/2)", and "1" for the dimensionless unit Unit(). str, to_dict and dimensions list base dimensions by name in Python string order, so uppercase comes first: A K cd kg m mol s.

    How symbols act on units

    A UnitRule says how an operator or function combines the units of its arguments, e.g. * multiplies them and sin needs a dimensionless argument. Every "op" and "fn" symbol of a SymbolLibrary has one (see add_symbol), so a custom symbol is described once, where it is defined:

    from fractions import Fraction

from SRToolkit.utils import FN_PREFIX, SymbolLibrary
from SRToolkit.utils.units import UnitRule

sl = SymbolLibrary.default_symbols(2)
sl.add_symbol("cbrt", "fn", FN_PREFIX, "np.cbrt({})", unit_rule=UnitRule.power(Fraction(1, 3)))

    Units are used by ConsistentUnits, by VariableInfo and by the grammar constraint DimensionalConsistency.

    def __init__(
    self, units: Optional[Mapping[str, Union[int, Fraction]]] = None, custom_units: Iterable[str] = ()
) -> None:
    custom = {custom_units} if isinstance(custom_units, str) else set(custom_units)
    invalid = sorted((n for n in custom if not (isinstance(n, str) and n.isidentifier())), key=repr)
    if invalid:
        raise ValueError(f"Unit: custom unit names must be valid Python identifiers, got {invalid}.")
    dims: Dict[str, Fraction] = {}
    for name, exponent in (units or {}).items():
        if not isinstance(exponent, (int, Fraction)) or isinstance(exponent, bool):
            raise TypeError(
                f"Unit: the exponent of {name!r} must be an int or a Fraction, got {type(exponent).__name__}."
            )
        if name in _DERIVED_UNITS:
            base: Mapping[str, Union[int, Fraction]] = _DERIVED_UNITS[name]
        elif name in _BASE_UNITS or name in custom:
            base = {name: 1}
        else:
            raise ValueError(
                f"Unit: {name!r} is not a predefined unit ({', '.join((*_BASE_UNITS, *_DERIVED_UNITS))}); "
                f"confirm a custom unit with custom_units=[{name!r}]."
            )
        for dim, k in base.items():
            dims[dim] = dims.get(dim, Fraction(0)) + Fraction(exponent) * k
    object.__setattr__(self, "_dims", tuple(sorted((name, exp) for name, exp in dims.items() if exp != 0)))

    def __mul__(self, other: Unit) -> Unit:
    """Return the product of two units: exponents of the same dimension add.

    Args:
        other: A unit.

    Returns:
        The product.
    """
    if not isinstance(other, Unit):
        return NotImplemented
    dims = dict(self._dims)
    for name, exp in other._dims:
        dims[name] = dims.get(name, Fraction(0)) + exp
    return Unit(dims, custom_units=dims)

    def __pow__(self, exponent: Union[int, Fraction]) -> Unit:
    """Return the unit raised to a rational power: every exponent is multiplied by it.

    Args:
        exponent: An ``int`` or a ``Fraction``. ``0`` gives the dimensionless unit.

    Returns:
        The power.

    Raises:
        TypeError: If ``exponent`` is not an ``int`` or a ``Fraction`` (e.g. a ``float``).

        raise TypeError(f"Unit: the power must be an int or a Fraction, got {type(exponent).__name__}.")
    dims = {name: exp * exponent for name, exp in self._dims}
    return Unit(dims, custom_units=dims)

    def __str__(self) -> str:
    """Return the unit as text: ``"1"`` if dimensionless, otherwise the factors in name order.

    A factor is ``<name>`` for exponent 1, ``<name>^<k>`` for another integer (``s^-2``) and
    ``<name>^(<p>/<q>)`` for a fraction, the sign inside the brackets (``m^(-1/2)``), separated
    by single spaces.

    Returns:
        The text, e.g. ``"kg m^2 s^-2"``.
    """
    if not self._dims:
        return "1"
    factors = []
    for name, exp in self._dims:
        if exp == 1:
            factors.append(name)
        else:
            factors.append(f"{name}^{exp.numerator if exp.denominator == 1 else f'({exp})'}")
    return " ".join(factors)

    UnitRule dataclass 

    UnitRule(kind: str, exponent: Optional[Fraction] = None)

    How an operator or function combines the units of its arguments.

    Immutable (assigning an attribute raises AttributeError) and hashable; rules can be copied and pickled, and are compared by kind and exponent. Use the class attributes and power; the constructor is not part of the API.

    Rule Arity Result Conflict when
    SAME 1 or 2 the arguments' unit with two arguments, their units differ
    MULTIPLY 2 product of the units never
    DIVIDE 2 left unit divided by right unit never
    EXPONENT 2 if the exponent is a single number token (defined in ConsistentUnits), the base unit to that power; otherwise dimensionless the exponent is not a number token and the base or the exponent is not dimensionless
    power(k) 1 the argument's unit to the power k never
    DIMENSIONLESS 1 or 2 dimensionless an argument is not dimensionless

    What counts as a number token, how conflicts are counted and the messages are defined by ConsistentUnits. The rules of the predefined symbols are listed in SymbolLibrary.default_symbols.

    Attributes:

    Name Type Description
    SAME UnitRule

    Arguments must share a unit, which the result has (+, floor).
    MULTIPLY UnitRule

    The result's unit is the product of the arguments' units (*).
    DIVIDE UnitRule

    The result's unit is the left unit divided by the right one (/).
    EXPONENT UnitRule

    A number exponent scales the base's unit; otherwise both must be dimensionless (^).
    DIMENSIONLESS UnitRule

    Arguments must be dimensionless, and so is the result (sin, exp).
    kind str

    The rule's name: "same", "multiply", "divide", "exponent", "power" or "dimensionless".
    exponent Optional[Fraction]

    k as a Fraction for power(k), otherwise None.

    Examples:

    >>> UnitRule.power(2).exponent
Fraction(2, 1)
>>> UnitRule.SAME.arities
(1, 2)

    arities property 

    arities: Tuple[int, ...]

    The numbers of arguments the rule accepts, as a tuple in increasing order, e.g. (1, 2).

def from_dict(cls, d: Mapping[str, Union[int, str, Fraction]]) -> UnitRule:
    """Rebuild a rule from the output of ``to_dict``.

    Other keys are ignored.

    Args:
        d: A dictionary with the key ``"kind"``, and ``"exponent"`` for ``"power"``, read as in
            [Unit.from_dict][SRToolkit.utils.units.Unit.from_dict].

    Returns:
        The rule.

    Raises:
        ValueError: If ``"kind"`` is missing or not one of the rules' names, or a power's
            exponent is missing or invalid.
    """
    kind = d.get("kind")
    if kind not in cls._ARITIES:
        raise ValueError(f"UnitRule.from_dict: unknown kind {kind!r}; expected one of {', '.join(cls._ARITIES)}.")
    if kind != "power":
        return cls(str(kind))
    if "exponent" not in d:
        raise ValueError("UnitRule.from_dict: a power rule needs an 'exponent'.")
    return cls("power", _parse_exponent(d["exponent"], "UnitRule.from_dict"))
