    Types

    SRToolkit.utils.types

    Shared constants, settings types and result dataclasses for SRToolkit.

    • Symbol types (VAR, CONST, FN, OP, LIT) tag the entries of a SymbolLibrary.
    • Precedence levels (OP_ADDITIVE, OP_MULTIPLICATIVE, OP_POWER, FN_PREFIX, FN_POSTFIX, LEAF) order symbols for parsing and printing. Custom operators can use values between the levels.
    • RankingSettings lists the keyword settings understood by the built-in ranking functions and the parameter estimator.
    • ModelResult (one evaluated expression) and EvalResult (one SR run) hold experiment outcomes. Each model has a Status. Both save to JSON through serialization, so everything stored in them must be a value listed there. The trace-based metrics of EvalResult are explained in sr_evaluator.

    VAR module-attribute 

    VAR = 'var'

    Symbol type of a variable (e.g. X_0).

    CONST module-attribute 

    CONST = 'const'

    Symbol type of a free constant whose value is fitted (e.g. C).

    FN module-attribute 

    FN = 'fn'

    Symbol type of a function (e.g. sin, or postfix ^2).

    OP module-attribute 

    OP = 'op'

    Symbol type of a binary operator (e.g. +).

    LIT module-attribute 

    LIT = 'lit'

    Symbol type of a literal with a fixed value (e.g. pi, 1).

    VALID_SYMBOL_TYPES module-attribute 

    VALID_SYMBOL_TYPES: Set[str] = {VAR, CONST, FN, OP, LIT}

    The set of valid symbol types: VAR, CONST, FN, OP and LIT.

    OP_ADDITIVE module-attribute 

    OP_ADDITIVE = 100

    Precedence of additive operators (+, -).

    OP_MULTIPLICATIVE module-attribute 

    OP_MULTIPLICATIVE = 200

    Precedence of multiplicative operators (*, /).

    OP_POWER module-attribute 

    OP_POWER = 300

    Precedence of the power operator (^).

    FN_PREFIX module-attribute 

    FN_PREFIX = 1000

    Precedence of prefix functions (sin(E)). It is higher than every operator precedence.

    FN_POSTFIX module-attribute 

    FN_POSTFIX = -1000

    Precedence of postfix functions (E^2). Negative, and distinct from the -1 that get_precedence returns for unknown symbols.

    LEAF module-attribute 

    LEAF = 1000

    Precedence stored for atoms (VAR, CONST, LIT). Atoms never take part in precedence comparisons. The large value prevents spurious parentheses if a high-precedence operator is added.

    Status module-attribute 

    Status = Literal['ok', 'invalid', 'rejected', 'undefined', 'error']

    Outcome of evaluating one expression, stored as ModelResult.status.

    • "ok": scored, with a finite error.
    • "invalid": not a well-formed expression; the parser raised an ExpressionParseError.
    • "rejected": well-formed, but it violates a limit of the task (max_constants, max_expr_length), so it was not scored.
    • "undefined": scored, but the ranking function gave a non-finite error, e.g. because the expression is undefined at some inputs (sqrt of a negative number, log(0)) or overflows. For RMSE this describes the fitted model: other constants might have been fine.
    • "error": the ranking function raised an exception for a well-formed expression. This is a failure of the evaluation, not of the expression.

    Every status except "ok" gets the error +inf.

    STATUSES module-attribute 

    STATUSES: Tuple[str, ...] = get_args(Status)

    The values of Status, in the same order. This is also the key order of status_counts.

    RankingSettings

    Bases: TypedDict

    Settings for the ranking functions, the parameter estimator and the evaluator's limits.

    Passed as **kwargs to SR_dataset, SR_evaluator, and ParameterEstimator, then handed to the active ranking's setup as a plain dict. All fields are optional.

    These are the keys the built-in rankings understand. A custom RankingFunction may read additional keys from the settings dict at runtime. Passing them through works, but a type checker will not know about them, so extend this TypedDict (or silence the call site) if you want them checked.

    Attributes:

    Name Type Description
    method str

    Optimization algorithm for parameter fitting. Default: "L-BFGS-B".
    tol float

    Termination tolerance for the optimizer. Default: 1e-6.
    gtol float

    Gradient-norm termination tolerance. Default: 1e-3.
    max_iter int

    Maximum optimizer iterations. Default: 100.
    constant_bounds Tuple[float, float]

    (lower, upper) bounds for constant values. The RMSE ranking samples initial values in them and passes them to the optimizer as bounds (used by methods that support bounds, such as "L-BFGS-B"); BED samples its constant vectors in them. Default: (-5, 5).
    initialization str

    Constant initialization strategy. "random" samples uniformly within constant_bounds; "mean" sets all constants to the midpoint. Default: "random".
    max_constants int

    Maximum number of free constants in an expression, enforced by the evaluator for every ranking. An expression with more gets status "rejected" and error +inf. A negative value disables the limit. Default: 8.
    max_expr_length int

    Maximum expression length in tokens, enforced like max_constants. A negative value disables the limit. Default: -1.
    backend str

    Backend used to compile expressions, by both rankings (ParameterEstimator and BED). "stack" uses the Cython-backed postfix stack machine; "codegen" generates Python/NumPy source via exec(); "stack_py" uses the pure-Python stack machine (faster than "stack" when the symbol library contains many custom symbols). Default: "stack".
    num_points_sampled int

    Number of domain points used when evaluating expression behavior for BED. -1 uses all points in X. Default: 64.
    samplers Optional[List[Any]]

    Per-feature list of Sampler that draw the BED evaluation points (num_points_sampled of them). Takes precedence over subsampling X. Default: None.
    bed_gt Optional[ndarray]

    Precomputed ground-truth behavior matrix for BED, one row per row of X and num_consts_sampled columns (so X must be the points it was computed on; samplers are ignored with it). If None, the behavior is computed from the ground truth, or taken from y. Default: None.
    ranking_seed Optional[int]

    Seed for the ranking's own randomness (BED points, behavior matrices, threshold), overriding the evaluator's seed. Set by SR_dataset.create_evaluator to the dataset's seed. Read only by BED. Default: None.
    bed_resample bool

    Read by SR_dataset. False fixes the BED objective per dataset (ranking_seed = dataset seed, 0 if unset); True resamples it every run from the run's seed. Default: False.
    num_consts_sampled int

    Number of constant vectors sampled per expression for BED. Default: 32.

    Examples:

    >>> settings: RankingSettings = {"method": "L-BFGS-B", "max_iter": 200}

    ModelResult dataclass 

    ModelResult(expr: List[str], error: float, parameters: Optional[ndarray] = None, ranking_data: Dict[str, Any] = dict(), augmentations: Dict[str, Dict[str, Any]] = dict(), status: Status = 'ok', status_detail: Optional[str] = None)

    One evaluated expression: an entry of EvalResult.all_models.

    Attributes:

    Name Type Description
    expr List[str]

    Token list representing the expression, e.g. ["C", "*", "X_0"].
    error float

    Numeric error under the ranking function (RMSE or BED). By convention +inf unless status is "ok"; this is not validated.
    parameters Optional[ndarray]

    Fitted constant values, shape (n_constants,). Set by the RMSE ranking only. None for other rankings and when nothing was fitted.
    ranking_data Dict[str, Any]

    Freeform payload carried over from the RankingResult extra dict of the ranking function that scored this expression. Empty for rankings that emit nothing beyond score/parameters.
    augmentations Dict[str, Dict[str, Any]]

    Per-augmenter data keyed by augmenter name. Populated by ResultAugmenter subclasses via add_augmentation.
    status Status

    How the evaluation ended; see Status.
    status_detail Optional[str]

    Why the status is not "ok": the parse error, the violated limit, the exception, or the non-finite score. None for "ok".

    Examples:

    >>> result = ModelResult(expr=["C", "*", "X_0"], error=0.42)
>>> result.error, result.status
(0.42, 'ok')

    @classmethod
def from_dict(cls, data: dict) -> "ModelResult":
    """Reconstruct a [ModelResult][SRToolkit.utils.types.ModelResult] from the output of [to_dict][SRToolkit.utils.types.ModelResult.to_dict].

    Args:
        data: Dictionary produced by [to_dict][SRToolkit.utils.types.ModelResult.to_dict],
            possibly after a JSON round trip. Unknown keys are ignored; other malformed
            input has undefined behaviour.

    Returns:
        The reconstructed [ModelResult][SRToolkit.utils.types.ModelResult].

    Raises:
        ValueError: If ``data`` has no ``status`` (it was saved before statuses were recorded),
            or its ``status`` is not one of [STATUSES][SRToolkit.utils.types.STATUSES].

    Examples:
        >>> result = ModelResult(expr=["X_0", "+", "C"], error=0.25)
        >>> ModelResult.from_dict(result.to_dict()).expr
        ['X_0', '+', 'C']
    """
    if "status" not in data:
        raise ValueError(
            "[ModelResult.from_dict] This model was saved by an older SRToolkit version, without an "
            "evaluation status, and cannot be loaded. Rerun the experiment."
        )
    if data["status"] not in STATUSES:
        raise ValueError(f"[ModelResult.from_dict] Unknown status {data['status']!r}; expected one of {STATUSES}.")
    return cls(
        expr=data["expr"],
        error=data["error"],
        parameters=_from_json_safe(data["parameters"]),
        ranking_data=_from_json_safe(data["ranking_data"]),
        augmentations=_from_json_safe(data["augmentations"]),
        status=data["status"],
        status_detail=data["status_detail"],
    )

    EvalResult dataclass 

    EvalResult(all_models: List[ModelResult], trace: List[int], approach_name: str, success_threshold: Optional[float] = None, top_k: int = 20, dataset_name: Optional[str] = None, metadata: Optional[dict] = None, wall_time: Optional[float] = None, augmentations: Dict[str, Dict[str, Any]] = dict())

    Result of a single SR experiment, as returned by SR_results[i].

    The stored data is the list of evaluated models and the evaluation trace; summary values such as min_error, best_expr, success and top_models() are derived from them. The ranking behind these summaries is cached. After construction models must not be modified or replaced, or the summaries can be stale.

    Attributes:

    Name Type Description
    all_models List[ModelResult]

    All evaluated models, in the order they were first evaluated. trace indexes into this list.
    trace List[int]

    The evaluation trace. trace[k] is the index into all_models of the expression requested by the (k+1)-th counted call to evaluate_expr (a call that counts toward max_evaluations; see sr_evaluator). Cache hits appear as repeated indices; calls made after evaluation was stopped are not recorded. Every entry must be a valid, non-negative index into all_models; otherwise behaviour is undefined.
    approach_name str

    Name of the SR approach, or empty string if not provided.
    success_threshold Optional[float]

    The experiment succeeds if an error strictly below this is found. A nan threshold is never reached. None if not set.
    top_k int

    Default number of models returned by top_models(). 0 means none; negative means all models.
    dataset_name Optional[str]

    Name of the dataset. None if not provided.
    metadata Optional[dict]

    The evaluator's metadata without dataset_name (e.g. model name, seed, and the dataset's metadata under "dataset_metadata"). None if there is none.
    wall_time Optional[float]

    Wall-clock duration in seconds of the approach's search for this experiment, measured around search() by the experiment runner. None if the result was not produced by a runner that records timing.
    augmentations Dict[str, Dict[str, Any]]

    Per-augmenter data keyed by augmenter name. Populated by ResultAugmenter subclasses via add_augmentation.

    Examples:

    >>> models = [ModelResult(expr=["X_0"], error=0.5), ModelResult(expr=["C", "*", "X_0"], error=0.05)]
>>> result = EvalResult(
...     all_models=models,
...     trace=[0, 1, 0],
...     approach_name="MyApproach",
...     success_threshold=0.1,
... )
>>> result.best_expr, result.min_error, result.success
('C*X_0', 0.05, True)

    def top_models(self, k: Optional[int] = None) -> List[ModelResult]:
    """Return the ``k`` best models, best first.

    Models with a finite error come first, sorted by error. Models whose error is not finite
    (``inf`` or ``nan``, not distinguished) come last. Only the error decides this, not the
    status; for results produced by the evaluator the two agree. Ties in error, and models
    that are all non-finite, are ordered by length (fewer tokens first), then by the order in
    which they were first evaluated. The returned objects are the ones in ``all_models``, not
    copies.

    Args:
        k: Number of models to return. Defaults to ``top_k``. ``0`` returns ``[]``; a negative
            value or one larger than the number of models returns all of them.

    Returns:
        The best ``k`` models, best first.

    Examples:
        >>> models = [ModelResult(expr=["X_0"], error=0.5), ModelResult(expr=["X_1"], error=0.1)]
        >>> result = EvalResult(all_models=models, trace=[0, 1], approach_name="", top_k=1)
        >>> [m.expr for m in result.top_models()]
        [['X_1']]
        >>> [m.expr for m in result.top_models(k=-1)]
        [['X_1'], ['X_0']]
    """
    if k is None:
        k = self.top_k
    ranking = self._ranking()
    if 0 <= k < len(ranking):
        ranking = ranking[:k]
    return [self.all_models[i] for i in ranking]

        >>> result.best_so_far()

    """
    history: List[Tuple[int, int]] = []
    best = None
    for call, index in enumerate(self.trace, start=1):
        error = self.all_models[index].error
        if math.isfinite(error) and (best is None or error < best):
            best = error
            history.append((call, index))
    return history

    def best_error_within(self, budgets: Sequence[int]) -> np.ndarray:
    """Return the best error found within each of the given numbers of counted calls.

    A budget larger than ``evaluation_calls`` gets the run's final best error. This is exact
    for a run that reached ``success_threshold``, but only an upper bound for a run that
    stopped early for another reason (see [sr_evaluator][SRToolkit.evaluation.sr_evaluator]).
    Keep budgets at or below the experiment's ``max_evaluations``.

    Args:
        budgets: Numbers of calls, as ``int`` or numpy integers. Non-integers have undefined
            behaviour.

    Returns:
        Array of shape ``(len(budgets),)``, in the order of ``budgets``, with the best finite
        error within each budget.
        ``NaN`` where no model had been scored successfully yet, including every budget
        ``<= 0``.

    Examples:
        >>> failed = ModelResult(["X_0", "X_1"], float("inf"), status="invalid")
        >>> models = [failed, ModelResult(["X_1"], 0.5), ModelResult(["C"], 0.1)]
        >>> result = EvalResult(all_models=models, trace=[0, 1, 2], approach_name="")
        >>> result.best_error_within([1, 2, 3, 10])
        array([nan, 0.5, 0.1, 0.1])
    """
    curve = np.full(len(budgets), np.nan)
    if not self.trace:
        return curve
    errors = np.array([self.all_models[i].error for i in self.trace], dtype=float)
    errors[~np.isfinite(errors)] = np.nan
    running = np.fmin.accumulate(errors)
    for j, budget in enumerate(budgets):
        if budget > 0:
            curve[j] = running[min(budget, len(running)) - 1]
    return curve

    """Reconstruct an [EvalResult][SRToolkit.utils.types.EvalResult] from the output of [to_dict][SRToolkit.utils.types.EvalResult.to_dict].

    Args:
        data: Dictionary produced by [to_dict][SRToolkit.utils.types.EvalResult.to_dict],
            possibly after a JSON round trip. Unknown keys are ignored; other malformed
            input has undefined behaviour.

    Returns:
        The reconstructed [EvalResult][SRToolkit.utils.types.EvalResult].

    Raises:
        ValueError: If ``format_version`` is not ``2`` (results saved before the evaluation
            trace was recorded have none), or if a model cannot be loaded (see
            [ModelResult.from_dict][SRToolkit.utils.types.ModelResult.from_dict]).

    Examples:
        >>> result = EvalResult(all_models=[ModelResult(["X_0"], 0.05)], trace=[0], approach_name="MyApproach")
        >>> EvalResult.from_dict(result.to_dict()).best_expr
        'X_0'
    """
    fmt = data.get("format_version")
    if fmt != 2:
        if fmt is None:
            raise ValueError(
                "[EvalResult.from_dict] These results were saved by an older SRToolkit version, without "
                "an evaluation trace, and cannot be loaded. Rerun the experiment; with ExperimentGrid, "
                "delete the old result files first, since existing files count as completed jobs."
            )
        raise ValueError(f"[EvalResult.from_dict] Unsupported format_version: {fmt!r}. Expected 2.")
    return cls(
        all_models=[ModelResult.from_dict(m) for m in data["all_models"]],
        trace=list(data["trace"]),
        approach_name=data["approach_name"],
        success_threshold=data["success_threshold"],
        top_k=data["top_k"],
        dataset_name=data["dataset_name"],
        metadata=_from_json_safe(data["metadata"]),
        wall_time=data["wall_time"],
        augmentations=_from_json_safe(data["augmentations"]),
    )
