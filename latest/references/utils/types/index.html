    Types

    SRToolkit.utils.types

    Shared constants and result dataclasses for SRToolkit.

    • Symbol types (VAR, CONST, FN, OP, LIT) tag the entries of a SymbolLibrary.
    • Precedence levels (OP_ADDITIVE, OP_MULTIPLICATIVE, OP_POWER, FN_PREFIX, FN_POSTFIX, LEAF) order symbols for parsing and printing. Custom operators can use values between the levels.
    • ModelResult (one evaluated expression) and EvalResult (one SR run) hold experiment outcomes. Each model has a Status. Both save to JSON through serialization, so everything stored in them must be a value listed there. CheckResult is the outcome of one check of an ExpressionConstraint; a ModelResult saves the failed advisory ones. The trace-based metrics of EvalResult are explained in evaluator.

    VAR module-attribute 

    VAR = 'var'

    Symbol type of a variable (e.g. X_0).

    CONST module-attribute 

    CONST = 'const'

    Symbol type of a free constant whose value is fitted (e.g. C).

    FN module-attribute 

    FN = 'fn'

    Symbol type of a function (e.g. sin, or postfix ^2).

    OP module-attribute 

    OP = 'op'

    Symbol type of a binary operator (e.g. +).

    LIT module-attribute 

    LIT = 'lit'

    Symbol type of a named constant, a symbol with a fixed value (e.g. pi, e).

    VALID_SYMBOL_TYPES module-attribute 

    VALID_SYMBOL_TYPES: set[str] = {VAR, CONST, FN, OP, LIT}

    The set of valid symbol types: VAR, CONST, FN, OP and LIT.

    OP_ADDITIVE module-attribute 

    OP_ADDITIVE = 100

    Precedence of additive operators (+, -).

    OP_MULTIPLICATIVE module-attribute 

    OP_MULTIPLICATIVE = 200

    Precedence of multiplicative operators (*, /).

    OP_POWER module-attribute 

    OP_POWER = 300

    Precedence of the power operator (^).

    FN_PREFIX module-attribute 

    FN_PREFIX = 1000

    Precedence of prefix functions (sin(E)). It is higher than every operator precedence.

    FN_POSTFIX module-attribute 

    FN_POSTFIX = -1000

    Precedence of postfix functions (E^2). Negative: any function precedence <= 0 makes a function postfix.

    LEAF module-attribute 

    LEAF = 1000

    Precedence stored for atoms (VAR, CONST, LIT). Atoms never take part in precedence comparisons. The large value prevents spurious parentheses if a high-precedence operator is added.

    Status module-attribute 

    Status = Literal['ok', 'invalid', 'rejected', 'undefined', 'error']

    Outcome of evaluating one expression, stored as ModelResult.status.

    • "ok": scored, with a finite error.
    • "invalid": not a well-formed expression; the parser raised an ExpressionParseError.
    • "rejected": well-formed, but it fails a check of a required constraint of the evaluator (by default the max_constants / max_expr_length limits), or the ranking function rejected it. A failed pre-check means it was not scored; a failed post-check means it was scored and its fit kept, but its error is still +inf.
    • "undefined": scored, but the ranking function gave a non-finite error, e.g. because the expression is undefined at some inputs (sqrt of a negative number, log(0)) or overflows. For RMSE this describes the fitted model: other constants might have been fine.
    • "error": the ranking function, or a check of a required constraint, raised an exception for a well-formed expression. This is a failure of the evaluation, not of the expression.

    Every status except "ok" gets the error +inf.

    STATUSES module-attribute 

    STATUSES: tuple[str, ...] = get_args(Status)

    The values of Status, in the same order. This is also the key order of status_counts.

    CheckResult dataclass 

    CheckResult(passed: bool = True, message: str = '', amount: float = 0.0, implemented: bool = True, constraint: str = '', stage: str = '', error: str | None = None)

    The outcome of one check of one ExpressionConstraint.

    Immutable (a frozen dataclass), so results can be shared. A constraint's pre_check / post_check returns one; it fills in passed, message and amount and leaves constraint and stage empty. When the Evaluator records a result, it stores a copy with constraint and stage filled in.

    Attributes:

    Name Type Description
    passed bool

    Whether the expression satisfies the constraint. True also when the check is not implemented.
    message str

    Why the check failed (e.g. "9 constants, limit 8"); may be empty. For a check that is not implemented, says so. The built-in constraints leave it empty when the check passes.
    amount float

    How far outside the constraint the expression is, in the constraint's own unit (e.g. 1.0 for one constant too many). The built-in constraints return a float that is greater than 0 exactly when the check fails, and 0.0 when it passes. Not validated, so a custom constraint may return any value.
    implemented bool

    False if the constraint has no such check. The evaluator then ignores the result, whatever passed says: nothing is recorded and nothing is rejected.
    constraint str

    The class name (type(constraint).__name__) of the constraint that produced it, filled in by the evaluator; "" otherwise.
    stage str

    "pre" or "post" for the check that produced it, filled in by the evaluator; "" otherwise.
    error str | None

    None, unless the check raised an exception or returned something other than a CheckResult (treated as a TypeError). The evaluator then records the check as failed, with error set to "<ExceptionType>: <message>", message to "raised <error>" and amount to inf. Such a result says nothing about the expression; leave it out when counting violations.

    Examples:

    >>> CheckResult().passed
True
>>> CheckResult(passed=False, message="9 constants, limit 8", amount=1.0).amount
1.0

    ModelResult dataclass 

    ModelResult(expr: list[str], error: float, parameters: ndarray | None = None, ranking_data: dict[str, Any] = dict(), augmentations: dict[str, dict[str, Any]] = dict(), status: Status = 'ok', status_detail: str | None = None, advisory_violations: list[CheckResult] = list(), free_constants: tuple[Constant, ...] | None = None)

    One evaluated expression: an entry of EvalResult.all_models.

    Two models are equal when their to_dict are equal.

    Attributes:

    Name Type Description
    expr list[str]

    Token list representing the expression, e.g. ["C", "*", "X_0"].
    error float

    Numeric error under the ranking function (RMSE or BED). By convention +inf unless status is "ok"; this is not validated.
    parameters ndarray | None

    Fitted values, one per parameter in the order of parameter_labels, shape (n_parameters,), fixed values included; free_constants holds the specs they were fitted under. Set by the RMSE ranking only. None for other rankings and when nothing was fitted.
    ranking_data dict[str, Any]

    Freeform payload carried over from the RankingResult extra dict of the ranking function that scored this expression. Empty for rankings that emit nothing beyond score/parameters.
    augmentations dict[str, dict[str, Any]]

    Per-augmenter data keyed by augmenter name. Populated by ResultAugmenter subclasses via add_augmentation.
    status Status

    How the evaluation ended; see Status.
    status_detail str | None

    Why the status is not "ok": the parse error, the failed check of a required constraint (e.g. "MaxConstants: 9 constants, limit 8"), the exception, or the non-finite score. None for "ok".
    advisory_violations list[CheckResult]

    The failed checks of the evaluator's advisory constraints, as CheckResults with constraint and stage filled in; a check that raised is included, with error set. Pre-checks are recorded for every expression the evaluator could parse, whatever its status; post-checks only for models with status "ok". Pre-check results come first; within a stage, results follow the order of the constraints. Empty if no check failed, if the evaluator has no advisory constraints, or if the status is "invalid". It never affects error. See expression_constraints.
    free_constants tuple[Constant, ...] | None

    The specs parameters were fitted under (priors, bounds, fixed values), as Constants sorted by label; None when no specs were given. Parameters without a spec (bare C always), and a spec's unset prior or bounds, used EvalResult.default_constant.

    Examples:

    >>> result = ModelResult(expr=["C", "*", "X_0"], error=0.42)
>>> result.error, result.status
(0.42, 'ok')

    def add_augmentation(self, name: str, data: dict[str, Any], aug_type: str) -> None:
    """Attach augmentation data produced by a [ResultAugmenter][SRToolkit.evaluation.results.ResultAugmenter].

    A shallow copy of ``data`` is stored in [augmentations][SRToolkit.utils.types.ModelResult] with
    ``"_type"`` set to ``aug_type``. The caller's dict is not modified, but nested values are
    shared with it. If ``name`` is already taken, the first free key among ``name_1``,
    ``name_2``, … is used instead, so existing data is never overwritten.

    Args:
        name: Key under which the augmentation is stored.
        data: Augmentation data. Its values must be ones that can be saved (see
            [serialization][SRToolkit.utils.serialization]); otherwise
            [to_dict][SRToolkit.utils.types.ModelResult.to_dict] raises ``TypeError``. A
            ``"_type"`` key in it is replaced in the stored copy.
        aug_type: Augmenter class name, stored under ``"_type"``.

    Examples:
        >>> result = ModelResult(expr=["X_0"], error=0.1)
        >>> result.add_augmentation("latex", {"value": "$X_0$"}, "LaTeXAugmenter")
        >>> result.add_augmentation("latex", {"value": "$X_0$"}, "LaTeXAugmenter")
        >>> list(result.augmentations)
        ['latex', 'latex_1']
    """
    _add_augmentation(self.augmentations, name, data, aug_type)

    @classmethod
def from_dict(cls, data: dict) -> "ModelResult":
    """Reconstruct a [ModelResult][SRToolkit.utils.types.ModelResult] from the output of [to_dict][SRToolkit.utils.types.ModelResult.to_dict].

    Args:
        data: Dictionary produced by [to_dict][SRToolkit.utils.types.ModelResult.to_dict],
            possibly after a JSON round trip. Unknown keys are ignored; a missing
            ``advisory_violations`` (results saved before it was recorded) loads as an empty
            list, a missing ``free_constants`` as ``None``; other malformed input has undefined
            behaviour. Each saved
            [CheckResult][SRToolkit.utils.types.CheckResult] comes back equal, field by field
            (an ``inf`` amount included).

    Returns:
        The reconstructed [ModelResult][SRToolkit.utils.types.ModelResult].

    Raises:
        ValueError: If ``data`` has no ``status`` (it was saved before statuses were recorded),
            or its ``status`` is not one of [STATUSES][SRToolkit.utils.types.STATUSES].
        ImportError: If the prior of a saved spec cannot be imported.

    Examples:
        >>> result = ModelResult(expr=["X_0", "+", "C"], error=0.25)
        >>> ModelResult.from_dict(result.to_dict()).expr
        ['X_0', '+', 'C']
    """
    if "status" not in data:
        raise ValueError(
            "[ModelResult.from_dict] This model was saved by an older SRToolkit version, without an "
            "evaluation status, and cannot be loaded. Rerun the experiment."
        )
    if data["status"] not in STATUSES:
        raise ValueError(f"[ModelResult.from_dict] Unknown status {data['status']!r}; expected one of {STATUSES}.")
    # Imported here: free_constants imports symbol_library, which imports this module.
    from .free_constants import Constant

    specs = data.get("free_constants")
    return cls(
        expr=data["expr"],
        error=data["error"],
        parameters=_from_json_safe(data["parameters"]),
        ranking_data=_from_json_safe(data["ranking_data"]),
        augmentations=_from_json_safe(data["augmentations"]),
        status=data["status"],
        status_detail=data["status_detail"],
        advisory_violations=[CheckResult(**r) for r in data.get("advisory_violations", [])],
        free_constants=None if specs is None else tuple(Constant.from_dict(c) for c in _from_json_safe(specs)),
    )

    EvalResult dataclass 

    EvalResult(all_models: list[ModelResult], trace: list[int], approach_name: str, success_threshold: float | None = None, top_k: int = 20, dataset_name: str | None = None, metadata: dict | None = None, wall_time: float | None = None, augmentations: dict[str, dict[str, Any]] = dict(), default_constant: Constant | None = None, stop_reason: str | None = None, summary: RunSummary | None = None, checkpoint: dict[str, Any] | None = None, limits: list[dict[str, Any]] = list(), skips: dict[str, int] = dict())

    Result of a single SR experiment, as returned by Results[i].

    The stored data is the list of evaluated models and the evaluation trace; summary values such as min_error, best_expr, success and top_models() are derived from them. The ranking behind these summaries is cached. After construction models must not be modified or replaced, or the summaries can be stale.

    A result of a long run can instead keep only its top models and a RunSummary (keep_all_models=False, see Evaluator.get_results); its methods then give the same answers, except where noted. All models of such a run stay in its checkpoint, if it was kept (see open_checkpoint).

    Attributes:

    Name Type Description
    all_models list[ModelResult]

    All evaluated models, in the order they were first evaluated. trace indexes into this list. With a summary, only the top_k best models, best first.
    trace list[int]

    The evaluation trace. trace[k] is the index into all_models of the expression requested by the (k+1)-th counted call to evaluate_expr (a call that counts toward max_evaluations; see evaluator). Cache hits appear as repeated indices; calls made after evaluation was stopped are not recorded. Every entry must be a valid, non-negative index into all_models; otherwise behaviour is undefined. Empty with a summary.
    approach_name str

    Name of the SR approach, or empty string if not provided.
    success_threshold float | None

    The experiment succeeds if an error strictly below this is found. A nan threshold is never reached. None if not set.
    top_k int

    Default number of models returned by top_models(). 0 means none; negative means all models.
    dataset_name str | None

    Name of the dataset. None if not provided.
    metadata dict | None

    The evaluator's metadata without dataset_name (e.g. model name, seed, and the dataset's metadata under "dataset_metadata"). None if there is none.
    wall_time float | None

    Seconds the run took, all sessions of a resumed run together (see Evaluator.wall_time). None if not known, e.g. from a checkpoint of a run that crashed before its first commit.
    augmentations dict[str, dict[str, Any]]

    Per-augmenter data keyed by augmenter name. Populated by ResultAugmenter subclasses via add_augmentation.
    default_constant Constant | None

    The default spec of the run (a Constant template): the spec of every parameter without one of its own (see ModelResult.free_constants). With it, Expression(model.expr, symbol_library, model.free_constants).resolve(result.default_constant) (see Expression.resolve) gives the complete specs of a saved model. None for results saved in format 2.
    stop_reason str | None

    Why the run ended: "success_threshold", "max_evaluations", the reason of a callback (e.g. "time_limit") or of the approach (see stop), or "returned" if the search returned without stopping the evaluator. Any other reason than the first two marks a run that ended with budget left. None for results saved before it was recorded.
    summary RunSummary | None

    What is kept of the run instead of all its models, or None (default) if all_models and trace are complete.
    checkpoint dict[str, Any] | None

    A reference to the run's checkpoint, {"path": ..., "fingerprint": ...} (the absolute path and the evaluator's fingerprint, see Checkpoints), or None. Results.from_checkpoint, evaluate_approach and ExperimentJob.run set it when the file still exists as they return; get_results does not. Only open_checkpoint uses it.
    limits list[dict[str, Any]]

    The run's limit segments: one for its start and one per extension that changed something (a plain resume adds none; see Extending runs). Each is a dict with calls (the calls kept when the segment starts), max_evaluations (negative: no limit), success_threshold (None: none), callbacks (the to_dict() of each callback; [] if calls were made without callbacks, None if the segment made no call of evaluate_expr or count_skip) and previous_stop_reason (why the segment before ended; None for the first, or after a crash). Check extended beside stop_reason before comparing runs. [] if not recorded (results saved before it was, or built by hand).
    skips dict[str, int]

    How many expressions the approach skipped without evaluating them, by reason (see count_skip), e.g. {"evaluated": 12, "rejected": 3}. Evaluated calls are not counted: calls that repeat an evaluated model (cache hits) number evaluation_calls - num_evaluated, rejected calls status_counts(per="call")["rejected"]. {} if the approach reported none, or if not recorded (results saved before it was, or built by hand).

    Examples:

    >>> models = [ModelResult(expr=["X_0"], error=0.5), ModelResult(expr=["C", "*", "X_0"], error=0.05)]
>>> result = EvalResult(
...     all_models=models,
...     trace=[0, 1, 0],
...     approach_name="MyApproach",
...     success_threshold=0.1,
... )
>>> result.best_expr, result.min_error, result.success
('C*X_0', 0.05, True)

    extended property

    ``summary.pareto_front``. The returned objects are the stored ones, not copies.

        >>> ["".join(m.expr) for m in result.pareto_front()]
        ['X_0', 'C*X_0']
    """

            raise ValueError("[EvalResult.pareto_front] The summary of this result has no Pareto front.")

    target = self.checkpoint["path"] if path is None else path
    store = ModelStore(target, "read")
    try:
        saved = store.get_header("fingerprint", {})
    except BaseException:
        store.close()
        raise

    changed = sorted(k for k in saved.keys() | expected.keys() if saved.get(k) != expected.get(k))

            f"these parameters differ: {', '.join(changed)}.{hint}"
        )
    return store

    def to_dict(self) -> dict:
    """Return a JSON-safe dictionary of this evaluation result.

    The dictionary can be passed to ``json.dump``. After a JSON round trip,
    [from_dict][SRToolkit.utils.types.EvalResult.from_dict] restores every field exactly
    (including ``metadata``, ``augmentations`` and each model, see
    [ModelResult.to_dict][SRToolkit.utils.types.ModelResult.to_dict]), as guaranteed by
    [serialization][SRToolkit.utils.serialization]. The one exception is that numpy scalars come
    back as Python scalars.

    Returns:
        A dictionary with ``"format_version": 4`` and one entry per field
        (``default_constant`` as its ``to_dict``, ``summary`` as a dictionary of its fields
        with each model as its ``to_dict``, each ``None`` if not set). It also holds the
        derived summaries ``min_error``, ``best_expr``, ``success``, ``num_evaluated``,
        ``evaluation_calls`` and ``status_counts`` (per model), for reading the file
        directly (with a ``summary``, the counts are its own). ``from_dict`` ignores them.
        ``min_error`` is ``nan`` for a result without
        models, which ``json`` writes as the non-standard token ``NaN``.

    Raises:
        TypeError: If ``metadata``, ``augmentations``, ``limits`` or ``skips`` contain a value that cannot be saved,
            or a model's ``to_dict`` raises (see
            [ModelResult.to_dict][SRToolkit.utils.types.ModelResult.to_dict]). The
            message gives its full path, e.g. ``all_models[3].ranking_data['z']``.

    Examples:
        >>> result = EvalResult(all_models=[ModelResult(["X_0"], 0.05)], trace=[0, 0], approach_name="MyApproach")
        >>> d = result.to_dict()
        >>> d["trace"], d["min_error"]
        ([0, 0], 0.05)
    """
    summary = None
    if self.summary is not None:
        summary = {
            "num_evaluated": self.summary.num_evaluated,
            "evaluation_calls": self.summary.evaluation_calls,
            "incumbents": [
                [call, index, model._to_dict(f"summary.incumbents[{i}].")]
                for i, (call, index, model) in enumerate(self.summary.incumbents)
            ],
            "status_counts": dict(self.summary.status_counts),
            "call_status_counts": dict(self.summary.call_status_counts),
            "pareto_front": (
                None
                if self.summary.pareto_front is None
                else [m._to_dict(f"summary.pareto_front[{i}].") for i, m in enumerate(self.summary.pareto_front)]
            ),
        }
    return {
        "format_version": 4,
        "min_error": float(self.min_error),
        "best_expr": self.best_expr,
        "success": self.success,
        "num_evaluated": self.num_evaluated,
        "evaluation_calls": self.evaluation_calls,
        "status_counts": self.status_counts(),
        "approach_name": self.approach_name,
        "dataset_name": self.dataset_name,
        "success_threshold": None if self.success_threshold is None else float(self.success_threshold),
        "top_k": int(self.top_k),
        "metadata": _to_json_safe(self.metadata, "metadata"),
        "wall_time": None if self.wall_time is None else float(self.wall_time),
        "stop_reason": self.stop_reason,
        "augmentations": _to_json_safe(self.augmentations, "augmentations"),
        "trace": [int(i) for i in self.trace],
        "all_models": [m._to_dict(f"all_models[{i}].") for i, m in enumerate(self.all_models)],
        "default_constant": (
            None
            if self.default_constant is None
            else _to_json_safe(self.default_constant.to_dict(), "default_constant")
        ),
        "summary": summary,
        "checkpoint": _to_json_safe(self.checkpoint, "checkpoint"),
        "limits": _to_json_safe(self.limits, "limits"),
        "skips": _to_json_safe(self.skips, "skips"),
    }

def from_dict(cls, data: dict) -> "EvalResult":
    """Reconstruct an [EvalResult][SRToolkit.utils.types.EvalResult] from the output of [to_dict][SRToolkit.utils.types.EvalResult.to_dict].

    Args:
        data: Dictionary produced by [to_dict][SRToolkit.utils.types.EvalResult.to_dict],
            possibly after a JSON round trip, of format 4, 3 (written before summaries and
            checkpoint references; ``summary`` and ``checkpoint`` load as ``None``) or 2
            (written before specs were recorded; ``default_constant`` and each model's
            ``free_constants`` load as ``None`` too). A missing ``stop_reason``, or a missing
            field of a saved ``summary`` that has a default, loads as ``None``; missing
            ``limits`` and ``skips`` load as ``[]`` and ``{}``. Unknown keys are
            ignored; other malformed input has undefined behaviour.

    Returns:
        The reconstructed [EvalResult][SRToolkit.utils.types.EvalResult].

    Raises:
        ValueError: If ``format_version`` is missing (results saved before the evaluation trace
            was recorded) or not ``2``, ``3`` or ``4``, or if a model cannot be loaded (see
            [ModelResult.from_dict][SRToolkit.utils.types.ModelResult.from_dict]).
        ImportError: If the prior of a saved spec cannot be imported.

    Examples:
        >>> result = EvalResult(all_models=[ModelResult(["X_0"], 0.05)], trace=[0], approach_name="MyApproach")
        >>> EvalResult.from_dict(result.to_dict()).best_expr
        'X_0'
    """
    fmt = data.get("format_version")
    if fmt not in (2, 3, 4):
        if fmt is None:
            raise ValueError(
                "[EvalResult.from_dict] These results were saved by an older SRToolkit version, without "
                "an evaluation trace, and cannot be loaded. Rerun the experiment; with ExperimentGrid, "
                "delete the old result files first, since existing files count as completed jobs."
            )
        raise ValueError(f"[EvalResult.from_dict] Unsupported format_version: {fmt!r}. Expected 2, 3 or 4.")
    # Imported here: free_constants imports symbol_library, which imports this module.
    from .free_constants import Constant

    default = data.get("default_constant")
    summary = data.get("summary")
    if summary is not None:
        # A field with a default may be missing (saved before it existed): it loads as None.
        values = {
            f.name: summary.get(f.name) if f.default is not dataclasses.MISSING else summary[f.name]
            for f in dataclasses.fields(RunSummary)
        }
        values["incumbents"] = [(call, index, ModelResult.from_dict(m)) for call, index, m in values["incumbents"]]
        if values["pareto_front"] is not None:
            values["pareto_front"] = [ModelResult.from_dict(m) for m in values["pareto_front"]]
        summary = RunSummary(**values)
    return cls(
        all_models=[ModelResult.from_dict(m) for m in data["all_models"]],
        trace=list(data["trace"]),
        approach_name=data["approach_name"],
        success_threshold=data["success_threshold"],
        top_k=data["top_k"],
        dataset_name=data["dataset_name"],
        metadata=_from_json_safe(data["metadata"]),
        wall_time=data["wall_time"],
        augmentations=_from_json_safe(data["augmentations"]),
        default_constant=None if default is None else Constant.from_dict(_from_json_safe(default)),
        stop_reason=data.get("stop_reason"),
        summary=summary,
        checkpoint=_from_json_safe(data.get("checkpoint")),
        limits=_from_json_safe(data.get("limits", [])),
        skips=_from_json_safe(data.get("skips", {})),
    )
