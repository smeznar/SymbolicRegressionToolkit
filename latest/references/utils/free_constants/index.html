    Free Constants

    SRToolkit.utils.free_constants

    Specifications of free constants: priors, bounds and fixed values.

    A free constant is a token of type "const" (C in the default SymbolLibrary) whose value is fitted to the data. It is unrelated to a named constant (a "lit" symbol such as pi), whose value is fixed by the library.

    A bare C is a new parameter at every occurrence; a labelled constant C_<int> (e.g. C_5) is one parameter however often it occurs. Labels are local to an expression: C_0 in two expressions are unrelated parameters. The parameters of an expression form a vector ordered by first appearance, as listed by parameter_labels.

    A Constant describes how one labelled constant is treated: the prior its starting points (and BED samples) are drawn from, the hard bounds of the fit, an optional value, and whether that value is fixed instead of fitted. Specs address constants by label, so to specify a constant write it labelled (C_0 instead of C). A bare C, and a labelled constant without a spec, use the default spec: a Constant template (no label) that applies to every parameter without a spec of its own. A spec's unset prior or bounds are also taken from it, so a fit is unbounded only when infinite bounds are given explicitly. A dataset's default spec is BackgroundKnowledge.default_constant; uniform_default builds the usual one, a uniform prior on a constant range with that range as bounds. resolve_constants combines the specs given for an expression with the default spec into one complete spec per parameter.

    Without specs, how constants are written does not matter: C_0*X_0 + C_0 and C_1*X_0 + C_1 are the same model. canonicalise writes them one way (a constant occurring once bare, a shared one labelled), e.g. to deduplicate candidates of an approach that writes labelled constants (evaluate_expr(canonicalise_constants=True)).

    Constant dataclass 

    Constant(label: str | None = None, prior: Sampler | None = None, bounds: tuple[float, float] | None = None, value: float | None = None, fixed: bool = False)

    Specification of one free constant.

    A spec with a label applies to every occurrence of that labelled constant in an expression. A spec without one is a template. A template used as the default spec (applied to every parameter that has no spec of its own, see uniform_default) must set prior and bounds and leave value and fixed unset.

    Parameters:

    Name Type Description Default
    label str | None

    The labelled-constant token the spec applies to, e.g. "C_5". None makes the spec a template. Whether the label occurs in an expression is checked by resolve_constants; a token the symbol library registers as a symbol (e.g. a named constant C_1) is never a labelled constant.

    		 None
    prior Sampler | None

    Distribution that starting points and BED samples are drawn from. None: the default spec's prior, filled in by resolve_constants.

    		 None
    bounds tuple[float, float] | None

    Hard (lower, upper) bounds of the fit: a pair of real numbers (length-2 sequence or array) with lower < upper. Either end may be infinite; (-inf, inf) fits without bounds. None: the default spec's bounds, filled in by resolve_constants.

    		 None
    value float | None

    The constant's value: used as is when fixed, otherwise the first starting point of the fit, which must lie in the closed interval bounds (checked against inherited bounds by resolve_constants). None draws the starting point from the prior.

    		 None
    fixed bool

    If True, the constant is not fitted and value is used as is, whatever the bounds (it must still be finite).

    		 False

    def to_dict(self) -> dict:
    """Return a JSON-safe dict of the spec.

    The prior is stored with its [to_dict][SRToolkit.dataset.sampling.Sampler.to_dict] and the
    bounds as a ``[lower, upper]`` list; infinite bounds stay ``float`` infinities (see
    [serialization][SRToolkit.utils.serialization]).

    Returns:
        A dict with the keys ``"label"``, ``"prior"``, ``"bounds"``, ``"value"`` and
        ``"fixed"``; unset fields are ``None``.

    Examples:
        >>> Constant(label="C_0", value=1.5).to_dict()
        {'label': 'C_0', 'prior': None, 'bounds': None, 'value': 1.5, 'fixed': False}
    """
    return {
        "label": self.label,
        "prior": None if self.prior is None else self.prior.to_dict(),
        "bounds": None if self.bounds is None else list(self.bounds),
        "value": self.value,
        "fixed": self.fixed,
    }

def from_dict(cls, d: dict) -> "Constant":
    """Rebuild a spec from [to_dict][SRToolkit.utils.free_constants.Constant.to_dict] output.

    Args:
        d: A dict as returned by ``to_dict``, also after a JSON round trip. Unknown keys are
            ignored.

    Returns:
        The spec, with the same ``to_dict`` as the one that was saved.

    Raises:
        KeyError: If a key of ``to_dict`` is missing from ``d``.
        ImportError: If the prior's sampler class cannot be imported.
        TypeError: If a value has the wrong type (see
            [Constant][SRToolkit.utils.free_constants.Constant]).
        ValueError: If the values are invalid (see
            [Constant][SRToolkit.utils.free_constants.Constant]).

    Examples:
        >>> from SRToolkit.dataset import UniformSampling
        >>> c = Constant(label="C_0", prior=UniformSampling(0.0, 2.0), bounds=(0.0, float("inf")))
        >>> Constant.from_dict(c.to_dict()).to_dict() == c.to_dict()
        True
    """
    # Imported here: SRToolkit.dataset imports this package.
    from SRToolkit.dataset.sampling import Sampler

    label, prior, bounds, value, fixed = d["label"], d["prior"], d["bounds"], d["value"], d["fixed"]
    return cls(
        label=label,
        prior=None if prior is None else Sampler.from_dict(prior),
        bounds=bounds,
        value=value,
        fixed=fixed,
    )

    def uniform_default(constant_bounds: tuple[float, float]) -> Constant:
    """Return the default spec with a uniform prior on, and bounds of, a constant range.

    Args:
        constant_bounds: The ``(lower, upper)`` range, as in
            [BackgroundKnowledge.constant_bounds][SRToolkit.dataset.background_knowledge.BackgroundKnowledge]:
            a pair of finite real numbers (length-2 sequence or array) with ``lower < upper``.

    Returns:
        A new template (``label=None``) with prior ``UniformSampling(lower, upper)`` (not mirrored)
        and bounds ``(lower, upper)`` as ``float``s.

    Raises:
        TypeError: If ``constant_bounds`` is not a pair of real numbers (``bool`` is
            not accepted as a number).
        ValueError: If ``constant_bounds`` is not finite or does not satisfy ``lower < upper``.

    Examples:
        >>> uniform_default((-5.0, 5.0)).bounds
        (-5.0, 5.0)
    """
    # Imported here: SRToolkit.dataset imports this package.
    from SRToolkit.dataset.sampling import UniformSampling

    template = Constant(bounds=constant_bounds)
    if template.bounds is None:
        raise TypeError("'constant_bounds' must be a pair of real numbers, got None.")
    lower, upper = template.bounds
    if not (math.isfinite(lower) and math.isfinite(upper)):
        raise ValueError(f"'constant_bounds' must be finite, got {constant_bounds!r}.")
    return replace(template, prior=UniformSampling(lower, upper))

    def resolve_constants(
    expr: list[str] | Node,
    free_constants: Sequence[Constant] | None,
    default_constant: Constant,
    symbol_library: SymbolLibrary | None = None,
) -> tuple[Constant, ...]:
    """Return one complete spec per parameter of an expression.

    Each labelled constant with a spec gets that spec, with a ``prior`` or ``bounds`` of ``None``
    taken from ``default_constant``. Every other parameter (each bare ``C``, and labelled constants
    without a spec) gets ``default_constant`` itself. Use it to see what an expression is fitted under, e.g. to
    resample the constants of a saved result.

    Args:
        expr: Expression as an infix token list or a [Node][SRToolkit.utils.expression_tree.Node].
        free_constants: Specs for labelled constants of ``expr``, in any order. ``None`` or empty
            gives every parameter the default spec.
        default_constant: The default spec, for parameters without a spec: a template with
            ``prior`` and ``bounds`` set and no ``label``, ``value`` or ``fixed``, e.g. from
            [uniform_default][SRToolkit.utils.free_constants.uniform_default].
        symbol_library: Symbol library used to recognise constants. ``None`` uses the active or
            default library.

    Returns:
        One spec per parameter, in the order of
        [parameter_labels][SRToolkit.utils.expression_tree.parameter_labels]; ``label`` is ``None``
        for every parameter that uses the default spec, labelled or not. Empty if ``expr`` has no free
        constants.

    Raises:
        TypeError: If ``expr`` is neither a list of token strings nor a
            [Node][SRToolkit.utils.expression_tree.Node].
        ValueError: If ``default_constant`` has a ``label``, ``value`` or ``fixed=True`` or lacks a
            ``prior`` or ``bounds``, a spec has no label, two specs share a label, a spec's label is
            not a labelled constant of ``expr``, or a spec that is not fixed has a ``value`` outside
            the bounds it takes from ``default_constant``. The message names the argument.

    Examples:
        >>> default = uniform_default((-5.0, 5.0))
        >>> specs = resolve_constants(
        ...     ["C", "*", "X_0", "+", "C_1"], [Constant(label="C_1", value=2.0, fixed=True)], default
        ... )
        >>> [(s.label, s.value, s.bounds) for s in specs]
        [(None, None, (-5.0, 5.0)), ('C_1', 2.0, (-5.0, 5.0))]
    """
    d = default_constant
    if d.label is not None or d.value is not None or d.fixed or d.prior is None or d.bounds is None:
        raise ValueError(
            f"'default_constant' must be a template with a prior and bounds and no label, value or fixed, got {d!r}."
        )
    labels = parameter_labels(expr, symbol_library)
    specs: dict[str, Constant] = {}
    for spec in free_constants or ():
        if spec.label is None:
            raise ValueError(f"Every spec in 'free_constants' needs a label, got {spec!r}.")
        if spec.label in specs:
            raise ValueError(f"Two specs in 'free_constants' share the label {spec.label!r}.")
        specs[spec.label] = spec
    unknown = sorted(set(specs) - set(labels))
    if unknown:
        raise ValueError(f"'free_constants' labels {unknown} are not labelled constants of the expression.")
    resolved = []
    for label in labels:
        given = specs.get(label) if label is not None else None
        if given is None:
            resolved.append(d)
            continue
        try:
            resolved.append(
                replace(
                    given,
                    prior=d.prior if given.prior is None else given.prior,
                    bounds=d.bounds if given.bounds is None else given.bounds,
                )
            )
        except ValueError as e:  # a free value outside the inherited bounds
            raise ValueError(f"'free_constants': {e}") from None
    return tuple(resolved)

    canonicalise 

    canonicalise(expr: list[str] | Node, symbol_library: SymbolLibrary | None = None) -> list[str]

    Rewrite the free constants of an expression in a canonical way.

    A parameter that occurs once is written bare (C, the library's constant symbol); one that occurs more than once is labelled. Labels C_0, C_1, ... are given out one per parameter (bare ones included) in the order of the parameter vector (see parameter_labels), skipping names the library registers as symbols, so a shared constant at position k is C_k unless an earlier name was skipped. Expressions that differ only in how their constants are written then have one form. The parameter vector keeps its length and order, and applying the rewrite again changes nothing. Only looks at tokens; does not parse. The rewrite drops the labels specs refer to, so apply it only to expressions without specs.

    def canonicalise(expr: list[str] | Node, symbol_library: SymbolLibrary | None = None) -> list[str]:
    """Rewrite the free constants of an expression in a canonical way.

    A parameter that occurs once is written bare (``C``, the library's constant symbol); one that
    occurs more than once is labelled. Labels ``C_0``, ``C_1``, ... are given out one per parameter
    (bare ones included) in the order of the parameter vector (see
    [parameter_labels][SRToolkit.utils.expression_tree.parameter_labels]), skipping names the library
    registers as symbols, so a shared constant at position ``k`` is ``C_k`` unless an earlier name was
    skipped. Expressions that differ only in how their constants are written then have one form. The
    parameter vector keeps its length and order, and applying the rewrite again changes nothing. Only
    looks at tokens; does not parse. The rewrite drops the labels specs refer to, so apply it only to
    expressions without specs.

    Args:
        expr: Expression as an infix token list or a [Node][SRToolkit.utils.expression_tree.Node].
        symbol_library: Symbol library used to recognise constants. ``None`` uses the active or
            default library.

    Returns:
        The canonical token list, as a new list. Equal to ``expr`` if it has only bare constants
        or the library has no constant symbol.

    Raises:
        TypeError: If ``expr`` is neither a list of token strings nor a
            [Node][SRToolkit.utils.expression_tree.Node].

    Examples:
        >>> "".join(canonicalise(["C_0", "*", "X_0", "+", "C_1", "*", "X_1"]))
        'C*X_0+C*X_1'
        >>> "".join(canonicalise(["C", "*", "X_0", "+", "C_5", "*", "X_1", "+", "C_5"]))
        'C*X_0+C_1*X_1+C_1'
    """
    if symbol_library is None:
        symbol_library = SymbolLibrary.get_or_default()
    tokens = _as_tokens(expr, symbol_library)
    symbol = symbol_library.constant_symbol
    indices = _constant_indices(tokens, symbol_library)
    names = []
    k = 0
    for _ in range(len(set(indices))):
        while f"{symbol}_{k}" in symbol_library.symbols:
            k += 1
        names.append(f"{symbol}_{k}")
        k += 1
    counts = Counter(indices)
    occurrences = iter(indices)
    result = []
    for token in tokens:
        if (s := symbol_library.get(token)) is not None and s.type == "const":
            index = next(occurrences)
            result.append(names[index] if counts[index] > 1 else str(symbol))
        else:
            result.append(token)
    return result
