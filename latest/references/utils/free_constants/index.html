    Free Constants

    SRToolkit.utils.free_constants

    Specifications of free constants: priors, bounds and fixed values.

    A free constant is a token of type "const" (C in the default SymbolLibrary) whose value is fitted to the data. It is unrelated to a named constant (a "lit" symbol such as pi), whose value is fixed by the library.

    A bare C is a new parameter at every occurrence; a labelled constant C_<int> (e.g. C_5) is one parameter however often it occurs. Labels are local to an expression: C_0 in two expressions are unrelated parameters. The parameters of an expression form a vector ordered by first appearance, as listed by Expression.parameter_labels.

    A Constant describes how one labelled constant is treated; an Expression carries the specs of its labelled constants. A spec gives the prior its starting points (and BED samples) are drawn from, the hard bounds of the fit, an optional value, and whether that value is fixed instead of fitted. Specs address constants by label, so to specify a constant write it labelled (C_0 instead of C). A bare C, and a labelled constant without a spec, use the default spec: a Constant template (no label) that applies to every parameter without a spec of its own. A spec's unset prior or bounds are also taken from it, so a fit is unbounded only when infinite bounds are given explicitly. A dataset's default spec is BackgroundKnowledge.default_constant; uniform_default builds the usual one, a uniform prior on a constant range with that range as bounds. Expression.resolve combines an expression's specs with the default spec into one complete spec per parameter.

    Without specs, how constants are written does not matter: C_0*X_0 + C_0 and C_1*X_0 + C_1 are the same model. canonicalise writes them one way (a constant occurring once bare, a shared one labelled), e.g. to deduplicate candidates of an approach that writes labelled constants (the evaluator setting canonicalise_constants).

    Constant dataclass 

    Constant(label: str | None = None, prior: Sampler | None = None, bounds: tuple[float, float] | None = None, value: float | None = None, fixed: bool = False)

    Specification of one free constant.

    A spec with a label applies to every occurrence of that labelled constant in an expression. A spec without one is a template. A template used as the default spec (applied to every parameter that has no spec of its own, see uniform_default) must set prior and bounds and leave value and fixed unset.

    Parameters:

    Name Type Description Default
    label str | None

    The labelled-constant token the spec applies to, e.g. "C_5". None makes the spec a template. Whether the label occurs in an expression is checked when an Expression is built; a token the symbol library registers as a symbol (e.g. a named constant C_1) is never a labelled constant.

    		 None
    prior Sampler | None

    Distribution that starting points and BED samples are drawn from. None: the default spec's prior, filled in by Expression.resolve.

    		 None
    bounds tuple[float, float] | None

    Hard (lower, upper) bounds of the fit: a pair of real numbers (length-2 sequence or array) with lower < upper. Either end may be infinite; (-inf, inf) fits without bounds. None: the default spec's bounds, filled in by Expression.resolve.

    		 None
    value float | None

    The constant's value: used as is when fixed, otherwise the first starting point of the fit, which must lie in the closed interval bounds (checked against inherited bounds by Expression.resolve). None draws the starting point from the prior.

    		 None
    fixed bool

    If True, the constant is not fitted and value is used as is, whatever the bounds (it must still be finite).

    		 False

    Attributes:

    Name Type Description
    label str | None

    As given.
    prior Sampler | None

    As given.
    bounds tuple[float, float] | None

    A tuple of two floats, or None.
    value float | None

    A float, or None.
    fixed bool

    As given.

    Raises:

    Type Description
    TypeError

    If label is not None or a string, prior is not None or a Sampler, bounds is not None or a pair of real numbers, value is not None or a real number, or fixed is not a bool (bool is not accepted as a number).
    ValueError

    If bounds contains nan or does not satisfy lower < upper, value is not finite, fixed is True without a value, or fixed is False and value lies outside bounds.

    Examples:

    >>> from SRToolkit.dataset import UniformSampling
>>> g = Constant(label="C_0", value=9.81, fixed=True)
>>> g.fixed
True
>>> Constant(label="C_1", prior=UniformSampling(0.0, 2.0), bounds=[0, float("inf")]).bounds
(0.0, inf)

    def to_dict(self) -> dict:
    """Return a JSON-safe dict of the spec.

    The prior is stored with its [to_dict][SRToolkit.dataset.sampling.Sampler.to_dict] and the
    bounds as a ``[lower, upper]`` list; infinite bounds stay ``float`` infinities (see
    [serialization][SRToolkit.utils.serialization]).

    Returns:
        A dict with the keys ``"label"``, ``"prior"``, ``"bounds"``, ``"value"`` and
        ``"fixed"``; unset fields are ``None``.

    Examples:
        >>> Constant(label="C_0", value=1.5).to_dict()
        {'label': 'C_0', 'prior': None, 'bounds': None, 'value': 1.5, 'fixed': False}
    """
    return {
        "label": self.label,
        "prior": None if self.prior is None else self.prior.to_dict(),
        "bounds": None if self.bounds is None else list(self.bounds),
        "value": self.value,
        "fixed": self.fixed,
    }

    @classmethod
def from_dict(cls, d: dict) -> "Constant":
    """Rebuild a spec from [to_dict][SRToolkit.utils.free_constants.Constant.to_dict] output.

    Args:
        d: A dict as returned by ``to_dict``, also after a JSON round trip. Unknown keys are
            ignored.

    Returns:
        The spec, with the same ``to_dict`` as the one that was saved.

    Raises:
        KeyError: If a key of ``to_dict`` is missing from ``d``.
        ImportError: If the prior's sampler class cannot be imported.
        TypeError: If a value has the wrong type (see
            [Constant][SRToolkit.utils.free_constants.Constant]).
        ValueError: If the values are invalid (see
            [Constant][SRToolkit.utils.free_constants.Constant]).

    Examples:
        >>> from SRToolkit.dataset import UniformSampling
        >>> c = Constant(label="C_0", prior=UniformSampling(0.0, 2.0), bounds=(0.0, float("inf")))
        >>> Constant.from_dict(c.to_dict()).to_dict() == c.to_dict()
        True
    """
    # Imported here: SRToolkit.dataset imports this package.
    from SRToolkit.dataset.sampling import Sampler

    label, prior, bounds, value, fixed = d["label"], d["prior"], d["bounds"], d["value"], d["fixed"]
    return cls(
        label=label,
        prior=None if prior is None else Sampler.from_dict(prior),
        bounds=bounds,
        value=value,
        fixed=fixed,
    )

    def uniform_default(constant_bounds: tuple[float, float]) -> Constant:
    """Return the default spec with a uniform prior on, and bounds of, a constant range.

    Args:
        constant_bounds: The ``(lower, upper)`` range, as in
            [BackgroundKnowledge.constant_bounds][SRToolkit.dataset.background_knowledge.BackgroundKnowledge]:
            a pair of finite real numbers (length-2 sequence or array) with ``lower < upper``.

    Returns:
        A new template (``label=None``) with prior ``UniformSampling(lower, upper)`` (not mirrored)
        and bounds ``(lower, upper)`` as ``float``s.

    Raises:
        TypeError: If ``constant_bounds`` is not a pair of real numbers (``bool`` is
            not accepted as a number).
        ValueError: If ``constant_bounds`` is not finite or does not satisfy ``lower < upper``.

    Examples:
        >>> uniform_default((-5.0, 5.0)).bounds
        (-5.0, 5.0)
    """
    # Imported here: SRToolkit.dataset imports this package.
    from SRToolkit.dataset.sampling import UniformSampling

    template = Constant(bounds=constant_bounds)
    if template.bounds is None:
        raise TypeError("'constant_bounds' must be a pair of real numbers, got None.")
    lower, upper = template.bounds
    if not (math.isfinite(lower) and math.isfinite(upper)):
        raise ValueError(f"'constant_bounds' must be finite, got {constant_bounds!r}.")
    return replace(template, prior=UniformSampling(lower, upper))
