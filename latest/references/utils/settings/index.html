    Settings

    SRToolkit.utils.settings

    Settings of an evaluation run: how expressions are evaluated, fitted and ranked.

    A Settings object holds named sections, one per component that reads them. Each section is a frozen dataclass, a subclass of SettingsSection, with its defaults and validation; its class attribute name is its key in Settings. The built-in sections are:

    Section Class Read by
    evaluator EvaluatorSettings the evaluator
    estimation EstimationSettings the parameter estimator
    minimize MinimizeSettings the parameter estimator's optimizer
    rmse RMSESettings RMSE ranking
    bed BEDSettings BED ranking

    A section that is not given holds its defaults, so Settings() is the default run. Each component reads its own section and ignores the others, so one Settings can configure several rankings at once. A custom ranking adds its own section under its own name.

    Facts about the task (constant bounds, the default spec of free constants, samplers, the ground truth's constants) are not settings; they belong to the dataset and its BackgroundKnowledge.

    Only the fields that differ from their defaults are saved (to_dict), and two Settings are equal when their saved forms are.

    Examples:

    >>> settings = Settings(minimize={"max_iter": 200}, evaluator=EvaluatorSettings(simplify_expr=True))
>>> settings.minimize.max_iter, settings.minimize.method
(200, 'L-BFGS-B')
>>> settings.replace(minimize={"tol": 1e-8}).minimize.max_iter
200
>>> settings.to_dict()["sections"]["minimize"]
{'max_iter': 200}

    A custom section:

    >>> from dataclasses import dataclass
>>> @dataclass(frozen=True, eq=False)
... class MyRankingSettings(SettingsSection):
...     name = "my_ranking"
...     alpha: float = 0.5
>>> Settings(my_ranking=MyRankingSettings(alpha=0.3)).get(MyRankingSettings).alpha
0.3

    SettingsSection

    Base class of a settings section.

    A subclass is a @dataclass(frozen=True, eq=False) with a default for every field and sets name. It validates its fields in __post_init__, raising TypeError for a value of the wrong type and ValueError for one out of range or not one of the allowed values, with a message naming <name>.<field>. Field values must be saveable (see serialization); a field holding an object with to_dict / from_dict declares that class as field(metadata={"codec": cls}).

    Two sections are equal when they have the same class and the same to_dict(), as Settings are. (Without eq=False, the dataclass compares field by field instead.)

    def changed(self) -> dict[str, Any]:
    """Return the fields whose values differ from their defaults, as ``{field: value}``.

    Values are compared by their saved form, so a value equal to the default is left out.
    """
    result = {}
    for f in dataclasses.fields(self):  # type: ignore[arg-type]
        value = getattr(self, f.name)
        default = f.default_factory() if f.default is dataclasses.MISSING else f.default  # type: ignore[misc]
        encoded = json.dumps(self._encode(f, value), sort_keys=True)
        if encoded != json.dumps(self._encode(f, default), sort_keys=True):
            result[f.name] = value
    return result

    def to_dict(self) -> dict[str, Any]:
    """Return the changed fields (see ``changed``) in their saved, JSON-compatible form.

    A field with a codec is saved through its value's ``to_dict``.
    """
    fields = {f.name: f for f in dataclasses.fields(self)}  # type: ignore[arg-type]
    return {k: self._encode(fields[k], v) for k, v in self.changed().items()}

    @classmethod
def from_dict(cls: type[_S], data: Mapping[str, Any]) -> _S:
    """Build the section from the output of ``to_dict``.

    Args:
        data: Saved field values by field name; missing fields take their defaults.

    Returns:
        The section.

    Raises:
        TypeError: If ``data`` names a field the section does not have, or as for the
            section's validation.
        ValueError: As for the section's validation.
    """
    fields = {f.name: f for f in dataclasses.fields(cls)}  # type: ignore[arg-type]
    unknown = sorted(set(data) - set(fields))
    if unknown:
        raise TypeError(f"[Settings] Section {cls.name!r} has no field(s) {unknown}.")
    values = {}
    for k, v in data.items():
        codec = fields[k].metadata.get("codec")
        values[k] = codec.from_dict(v) if codec is not None and v is not None else _from_json_safe(v)
    return cls(**values)

    Name Type Description
    simplify_expr bool

    Simplify every expression the evaluator scores or looks up, and score and store the simplified form, so inputs that simplify alike share one cache entry. Slower; the stored expression is never longer than the input (brackets aside). Default False.
    canonicalise_constants bool

    Canonicalise every expression after simplifying and folding, so C_1*X_0 + C_1 after C_0*X_0 + C_0 is a cache hit. Not applied to an expression that still has free-constant specs after simplifying and folding. Default False.
    fold_constants Literal['none', 'default', 'keep']

    mode of fold ("none", "default" or "keep") for every expression scored or looked up; the folded form is a different hypothesis. With simplify_expr, simplify folds as part of simplifying. Default "none".
    simplify_rules SimplificationRules

    Rewrite rules. Default DefaultRules().
    simplify_max_iterations int

    Maximum number of rewrite steps, a non-negative int. Default 30.
    simplify_max_nodes int

    E-graph growth limit (see simplify's max_nodes), a non-negative int. Default 10_000.
    simplify_max_time float | None

    Time limit in seconds, a positive finite number, or None for none. With a time limit, what is scored can depend on the machine. Default None.
    simplify_fold_aware bool

    Used when fold_constants is not "none": False is faster and folds less. Default True.
    max_consecutive_skips int

    Evaluation stops with the reason "max_consecutive_skips" after this many skips in a row (see count_skip); negative for no limit. Default 10000.
    max_constants int

    Shorthand for the required constraint MaxConstants, an int; negative for no limit. Default 8.
    max_expr_length int

    Shorthand for the required constraint MaxTokens (infix tokens, brackets included), an int; negative for no limit. Default -1.
    backend Literal['stack', 'codegen', 'stack_py']

    How expressions are compiled, by every ranking and the parameter estimator: "stack" (Cython stack machine), "codegen" (generated NumPy source) or "stack_py" (pure-Python stack machine, faster with many custom symbols). Default "stack".
    ranking_seed int | None

    Seed of the ranking's randomness (BED's points and behaviours, the starting points of fits), a non-negative int, in place of the evaluator's seed; None uses the evaluator's seed. SR_dataset.create_evaluator sets it to the dataset's seed unless the dataset resamples its objective each run. Default None.

    Raises:

    Type Description
    TypeError

    If simplify_expr, canonicalise_constants or simplify_fold_aware is not a bool; simplify_rules is not a SimplificationRules; simplify_max_time is not a number or None; or simplify_max_iterations, simplify_max_nodes, max_consecutive_skips, max_constants, max_expr_length or ranking_seed is not an int (None allowed for ranking_seed).
    ValueError

    def get(self, cls: type[_S]) -> _S:
    """Return the section stored under ``cls.name``, or ``cls()`` (its defaults) if there is none.

    Args:
        cls: The section class.

    Returns:
        The stored section, or ``cls()``.

    Raises:
        TypeError: If the section stored under ``cls.name`` is not a ``cls``.
    """
    section = self._sections.get(cls.name)
    if section is None:
        return cls()
    if not isinstance(section, cls):
        raise TypeError(f"[Settings] Section {cls.name!r} holds a {type(section).__name__}, not a {cls.__name__}.")
    return section

    def replace(self, **sections: SettingsSection | Mapping[str, Any]) -> Settings:
    """Return a copy with sections replaced or updated; ``self`` is unchanged.

    Args:
        **sections: Sections by name. An instance replaces the section; a dict of fields
            updates the current one (a custom section only if it is present). ``None`` is not
            accepted; reset a section with an instance of its defaults. Sections not named are
            kept.

    Returns:
        The new settings.

    Raises:
        ValueError: As for the constructor (a dict for a custom section that is not present).
        TypeError: As for the constructor, or if a value is ``None``.
    """
    new = dict(self._sections)
    for name, value in sections.items():
        new[name] = _as_section(name, value, new.get(name))
    result = Settings.__new__(Settings)
    object.__setattr__(result, "_sections", new)
    return result

    def to_dict(self) -> dict[str, Any]:
    """Return the settings as a JSON-compatible dict (arrays as serialization markers).

    Returns:
        ``{"format_version": 1, "sections": {name: fields}}`` with the changed fields of each
        section (see [changed][SRToolkit.utils.settings.SettingsSection.changed]); sections
        without changes are left out. The fields of a custom section also hold
        ``"section_class"``, its import path (``module.QualName``).
    """
    out: dict[str, Any] = {}
    for name, section in self._sections.items():
        fields = section.to_dict()
        if not fields:
            continue
        if name not in _BUILT_IN:
            fields = {"section_class": f"{type(section).__module__}.{type(section).__qualname__}", **fields}
        out[name] = fields
    return {"format_version": 1, "sections": out}

    @classmethod
def from_dict(cls, data: Mapping[str, Any]) -> Settings:
    """Rebuild settings from the output of ``to_dict``.

    A dict with a top-level ``_bundle`` key is first bound with
    [bind_config][SRToolkit.bundle.bind_config], so custom section classes resolve to an
    installed ``.srtk`` bundle.

    Args:
        data: The output of [to_dict][SRToolkit.utils.settings.Settings.to_dict].

    Returns:
        The settings.

    Raises:
        ValueError: If ``format_version`` is not ``1`` or a section without
            ``"section_class"`` is not built in; as for the constructor.
        ImportError: If a ``"section_class"`` cannot be imported.
        TypeError: If ``"sections"`` is not a dict of dicts, or a ``"section_class"`` is not a
            subclass of ``SettingsSection`` or is ``SettingsSection`` itself; as for the
            constructor.
    """
    data = _auto_bind(dict(data))
    if data.get("format_version") != 1:
        raise ValueError(f"[Settings] Unsupported format_version: {data.get('format_version')!r}. Expected 1.")
    sections: dict[str, Any] = {}
    sections_data = data.get("sections", {})
    if not isinstance(sections_data, Mapping) or not all(isinstance(e, Mapping) for e in sections_data.values()):
        raise TypeError("[Settings] 'sections' must be a dict of dicts, one per section.")
    for name, entry in sections_data.items():
        entry = dict(entry)
        path = entry.pop("section_class", None)
        if path is not None:
            section_cls = _import_class(path, "settings section", SettingsSection)
        elif name in _BUILT_IN:
            section_cls = _BUILT_IN[name]
        else:
            raise ValueError(f"[Settings] Unknown section {name!r} without a section_class.")
        sections[name] = section_cls.from_dict(entry)
    return cls(**sections)
