    Callbacks

    SRToolkit.evaluation.callbacks

    Event-driven callback system for monitoring and controlling SR evaluation.

    Provides event dataclasses fired during evaluation, the SR_callback base class for implementing custom callbacks, a CallbackDispatcher for managing multiple callbacks, and built-in implementations for progress display, early stopping, and logging.

    SR_callback

    Bases: ABC

    Abstract base class for SR evaluation callbacks.

    Implement only the methods you need. To stop the search, return a reason (a str) from on_expr_evaluated, on_best_expression or on_skip; it is recorded as the run's stop_reason unless evaluation has already stopped (the first reason is kept). False also stops, with the reason "callback:<ClassName>". Return True or None to continue.

    Examples:

    >>> class PrintBestCallback(SR_callback):
...     def on_best_expression(self, event):
...         print(f"New best: {event.expression} (error={event.error:.4g})")
>>> cb = PrintBestCallback()
>>> cb.on_best_expression(BestExpressionFound("", "X_0+C", 0.01, 5))
New best: X_0+C (error=0.01)

    @classmethod
def from_config_dict(cls, config: dict) -> "SR_callback":
    """Reconstruct a callback from a config dict that includes a ``callback_class`` path.

    This is the self-dispatching counterpart to
    [from_dict][SRToolkit.evaluation.callbacks.SR_callback.from_dict]: it binds the
    config to any installed ``.srtk`` bundle, resolves the concrete callback class named
    by ``callback_class``, and delegates to that class's
    [from_dict][SRToolkit.evaluation.callbacks.SR_callback.from_dict]. Mirrors
    [SR_dataset.from_dict][SRToolkit.dataset.sr_dataset.SR_dataset.from_dict], which
    resolves its own class the same way.

    Args:
        config: A serialised callback config containing a ``callback_class`` key, as
            produced by
            [to_dict][SRToolkit.evaluation.callbacks.SR_callback.to_dict].

    Returns:
        A new instance of the concrete callback class.

    Raises:
        ImportError: If ``callback_class`` cannot be imported (e.g. its ``.srtk`` bundle
            is not installed, or the config has no ``_bundle`` key and was never bound).
        TypeError: If ``callback_class`` is not an SR_callback subclass.
    """
    config = _auto_bind(config)
    target_cls = _import_class(config["callback_class"], "callback", SR_callback)
    return target_cls.from_dict(config)

    def on_expr_evaluated(self, event: ExprEvaluated) -> str | None:
    """Dispatch to all callbacks and return the first stop reason.

    Args:
        event: Data about the evaluated expression.

    Returns:
        The reason of the first callback (in order) that asked to stop, ``"callback:<ClassName>"``

    def set_state(self, states: list[dict]) -> None:
    """Restore the states saved by an earlier dispatcher's ``get_state``.

    The state at each position goes to the callback at the same position if its import path
    (``callback_class``) is the same, and callbacks without a saved state are not called. A
    non-empty state (not ``{}``, which
    [get_state][SRToolkit.evaluation.callbacks.SR_callback.get_state] returns by default) whose
    class is only at other positions is dropped with a ``UserWarning``: the callbacks were
    reordered, so e.g. a time limit would start counting from zero. A state of a callback that
    is no longer there is dropped silently.

    Args:
        states: The saved states.
    """
    classes = [cb.to_dict()["callback_class"] for cb in self._callbacks]
    for i, saved in enumerate(states):
        if i < len(classes) and saved["callback_class"] == classes[i]:
            self._callbacks[i].set_state(saved["state"])
        elif saved["state"] and saved["callback_class"] in classes:
            warnings.warn(
                f"[CallbackDispatcher] The saved state of {saved['callback_class']} (position {i}) is "
                "dropped: that class is now at another position.",
                UserWarning,
            )

    TimeLimitCallback 

    TimeLimitCallback(time_limit: float | timedelta)

    Bases: SR_callback

    Stops the search once a wall-clock time limit has elapsed.

    The timer starts when the experiment begins (on_experiment_start) and uses time.monotonic so it is unaffected by system clock adjustments. The stop request (reason "time_limit") is issued from the next expression evaluation or skip once time_limit seconds have elapsed, so the search may run slightly past time_limit depending on the time between consecutive evaluations and skips.

    In a resumed run the limit spans all sessions: the time used up to the last snapshot is restored from the checkpoint. Time after that snapshot in a session that crashed is not counted.

60.0

    LoggingCallback 

    LoggingCallback(log_file: str | None = None)

    Bases: SR_callback

    Logs each new best expression to stdout or a file.

    log_file may contain placeholders that are resolved at experiment start using fields from ExperimentEvent. Available placeholders: {dataset_name},{approach_name}, {seed}. Using per-experiment placeholders (e.g. {seed}) gives each job its own file, which is the recommended approach for parallel execution.

    When multiple jobs share the same resolved file path, writes are protected by fcntl.flock (POSIX advisory locking) so concurrent processes on Linux / macOS do not corrupt each other's output. On Windows or network filesystems where flock is unavailable the lock is silently skipped.

    Examples:

    >>> cb = LoggingCallback()

...                                        success_threshold=0, approach_name="ta"))

    def on_best_expression(self, event: BestExpressionFound) -> None:

    if self._resolved_log_file is not None:
