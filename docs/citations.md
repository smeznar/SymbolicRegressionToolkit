# Citations

This page lists how to cite SRToolkit and the publications behind the benchmarks and approaches
included in the toolkit. Click any entry to expand it and copy the BibTeX.

## Citing SRToolkit { #cite-srtoolkit }

If you use SRToolkit in your research, please cite:

??? quote "Mežnar et al. (2026) — SRToolkit: Shared Infrastructure for Symbolic Regression Research"
    Mežnar, S., Todorovski, L. & Džeroski, S. (2026). *IEEE WCCI 2026 Workshop on Symbolic
    Regression (SymReg 2026)*, oral presentation.
    [:material-link-variant: https://openreview.net/forum?id=du21XftP2Q](https://openreview.net/forum?id=du21XftP2Q)

    ```bibtex
    @inproceedings{Meznar2026SRToolkit,
      title     = {{SRToolkit: Shared Infrastructure for Symbolic Regression Research}},
      author    = {Me{\v{z}}nar, Sebastian and Todorovski, Ljup{\v{c}}o
                   and D{\v{z}}eroski, Sa{\v{s}}o},
      booktitle = {IEEE WCCI 2026 Workshop on Symbolic Regression (SymReg 2026)},
      year      = {2026},
      url       = {https://openreview.net/forum?id=du21XftP2Q}
    }
    ```

To cite a specific version of the software, use:

??? quote "Mežnar (2026) — SRToolkit, version 1.6.0"
    Mežnar, S. (2026). *SRToolkit: Symbolic Regression / Equation Discovery Benchmark Toolkit*,
    version 1.6.0.
    [:material-link-variant: https://github.com/smeznar/SymbolicRegressionToolkit](https://github.com/smeznar/SymbolicRegressionToolkit)

    ```bibtex
    @software{Meznar2026SRToolkitSoftware,
      title   = {{SRToolkit: Symbolic Regression / Equation Discovery Benchmark Toolkit}},
      author  = {Me{\v{z}}nar, Sebastian},
      year    = {2026},
      version = {1.6.0},
      url     = {https://github.com/smeznar/SymbolicRegressionToolkit}
    }
    ```

## Publications using SRToolkit { #cite-using-srtoolkit }

??? quote "Drnovšek (2026) — Equation discovery with Monte Carlo tree search"
    Drnovšek, T. (2026). *Odkrivanje enačb z drevesnim preiskovanjem Monte Carlo*
    [Equation discovery with Monte Carlo tree search]. Master's thesis, University of Ljubljana,
    Faculty of Mathematics and Physics. In Slovenian. Implements the Grams approach (grammar-based
    Monte Carlo tree search) on SRToolkit.
